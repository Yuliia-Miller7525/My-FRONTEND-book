Підключення JS до HTML

1. Створюємо файл з розширенням .js і підключається через src. 

<!-- index.html -->
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Мій проект</title>
  <!-- Підключення файлу main.js в head -->
  <script src="main.js" defer></script>
</head>
<body>
  <h1>Привіт, світ!</h1>
  <!-- Підключення файлу main.js перед </body>-->
  <script src="main.js"></script>
</body>
</html>

Порада: Атрибут defer каже браузеру завантажувати скрипт у фоновому режимі й виконувати його тільки після того, як весь HTML-документ буде повністю завантажений.

Атрибут async каже браузеру завантажувати скрипт у фоновому режимі паралельно з парсингом HTML. Щойно файл завантажується — браузер одразу зупиняє побудову HTML і виконує скрипт, тобто той скрипт, що завантажився швидше, виконається першим.

Важливе порівняння (async vs defer):

  • Звичайний скрипт (без нічого): Браузер зупиняє завантаження HTML, завантажує файл, виконує файл, продовжує HTML.
  • async: HTML і файл завантажуються паралельно. Файл виконується одразу по готовності (HTML на цей час зупиняється).
  • defer: HTML і файл завантажуються паралельно. Файл чекає, поки весь HTML повністю побудується, і виконується в кінці.

2. Код пишеться безпосередньо всередині HTML-тегу script. 

<script>
    console.log("Це внутрішній скрипт!");
</script>

Змінні (Variables)

Змінна - це "контейнер" для збереження даних.

var

Перший спосіб оголошення змінних у JavaScript - уже застарілий.

Не рекомендується в сучасному JS через проблеми з зоною видимості - зазвичай ми взагалі не використовуємо його.

let

Було введене у стандарті ECMAScript 6 (ES6) і стало покращенням у порівнянні з var - найсучасніший спосіб оголошення.

Використовується для оголошення змінної, значення якої можна змінювати.

const

Схоже на let, але використовується для оголошення змінної, яку не можна повторно переприсвоїти.

Для стислості можна поєднати оголошення змінної та запис даних в один рядок: 

let user = 'Josh', age = 25, message = 'Hello';

Багаторядковий варіант трохи довший, але легший для читання: 

let user = 'Josh';
let age = 25;
let message = 'Hello';

Типи даних (Data Types)

Примітивні Типи Даних

Вони володіють простою структурою та передаються за значенням, що означає, що при копіюванні одного значення в інше створюється нова копія даних.

  • Number - використовується для представлення числових значень, як цілих, так і чисел з плаваючою крапкою: 42, 3.14.
  • BigInt - озволяє представляти дуже великі цілі числа, які не можуть бути точно виражені типом Number.
  • String - це набір символів, які використовуються для представлення текстової інформації. Вони можуть бути створені, використовуючи одинарні (''), подвійні ("") або навіть багаторядкові (``) лапки, які дозволяють вставляти змінні та вирази всередину рядка через ${}.
  • Boolean є фундаментальними для умовного виконання коду та виразів. У JavaScript існують два можливих значення булевого типу: true (істина) і false (неправда).
  • Null - вказує на відсутність значення, використовується для присвоєння змінної порожнього або невідомого значення.
  • Undefined - вказує на змінну, яка була оголошена, але не має значення, використовується для перевірок, чи була змінна призначена.
  • Symbol - використовується для створення унікальних ідентифікаторів в об'єктах.

Об'єктні Типи Даних

Вони володіють складною структурою та передаються за посиланням, що означає, що при копіюванні створюється посилання на той самий об'єкт.

  • Object — це самостійна одиниця, що має властивості і методи. Порівняємо, наприклад, із чашкою. У чашки є колір, форма, вага, матеріал, з якого вона виготовлена, і т.д. Так само, об'єкти JavaScript мають властивості, які визначають їх характеристики.
  • Array (масив - частина типа Object) — це впорядкована колекція значень. Значення в масиві називаються елементами, і кожен елемент характеризується числовою позицією в масиві, яка називається індексом.
    Масиви в мові JavaScript є не типізованими: елементи масиву можуть мати будь-який тип, причому різні елементи одного і того ж масиву можуть мати різні типи. Та не мають окремого типу, бо відносяться до об'єкта.
  • Function (Функції) — об'єкти, які є викливаними (callable). Вони можуть мати власні властивості та методи.
  • Вбудовані об'єкти — Date (робота з датами та часом), RegExp (регулярні вирази), Map та Set (колекції з унікальними значеннями та довільними ключами).

Перетворення типів (Type Conversion)

Перетворення типів — це процес зміни типу даних одного значення на інший.

У JavaScript існує явне та неявне перетворення типів.

Явне перетворення типів (Explicit Type Conversion) — це перетворення типу даних, яке програміст виконує самостійно за допомогою спеціальних функцій або методів. 

let value = "25";

let number = Number(value);
let text = String(100);
let boolean = Boolean(1);

console.log(number);  // 25
console.log(text);    // "100"
console.log(boolean); // true

Неявне перетворення типів (Implicit Type Conversion) — це автоматична зміна типу даних, яку JavaScript виконує під час обчислення виразів або виконання операцій. 

console.log("5" + 2);  // "52"
console.log("5" - 2);  // 3
console.log(5 == "5"); // true
console.log(5 === "5"); // false

Округлення чисел (Number Rounding)

Math.round()


Округлює число до найближчого цілого. Якщо дробова частина дорівнює 0.5 або більше, число округлюється до більшого цілого. 


console.log(Math.round(4.3)); // 4
console.log(Math.round(4.7)); // 5
console.log(Math.round(-4.5)); // -4

Math.floor()


Округлює число вниз до найближчого цілого. Для від'ємних чисел округлення відбувається у напрямку меншого значення. 


console.log(Math.floor(4.9)); // 4
console.log(Math.floor(4.1)); // 4
console.log(Math.floor(-4.2)); // -5

Math.ceil()


Округлює число вгору до найближчого цілого. Для від'ємних чисел округлення відбувається у напрямку більшого значення. 


console.log(Math.ceil(4.1)); // 5
console.log(Math.ceil(4.9)); // 5
console.log(Math.ceil(-4.8)); // -4

Math.trunc()


Видаляє дробову частину числа без округлення, залишаючи лише цілу частину. 


console.log(Math.trunc(4.9)); // 4
console.log(Math.trunc(4.1)); // 4
console.log(Math.trunc(-4.9)); // -4

toFixed()


Округлює число до заданої кількості знаків після десяткової крапки та повертає результат у вигляді рядка (String). 


let number = 3.14159;

console.log(number.toFixed(2)); // "3.14"
console.log(number.toFixed(3)); // "3.142"
console.log(number.toFixed(0)); // "3"

Робота з рядками (String)

Шаблонні рядки (Template Literals)

Шаблонні рядки — це спосіб створення рядків за допомогою зворотних лапок (` `). Вони дозволяють вставляти змінні та вирази всередину тексту за допомогою конструкції ${expression}, а також створювати багаторядкові рядки. 

let name = "Alex";
let age = 25;

let message = `Мене звати ${name}, мені ${age} років.`;

console.log(message);

Доступ до символів рядка

Доступ до окремих символів рядка здійснюється за допомогою індексу. Індексація починається з 0. Для отримання символу можна використовувати квадратні дужки [] або метод charAt(). 

let text = "JavaScript";

console.log(text[0]);      // "J"
console.log(text[4]);      // "S"
console.log(text.charAt(1)); // "a"

Властивість length

length — властивість, яка повертає кількість UTF-16 кодових одиниць у рядку. 

let text = "Hello";

console.log(text.length); // 5

Заміна підстроки (replace(), replaceAll())

replace() — метод, який повертає новий рядок із заміненим першим входженням заданої підстроки. 

let text = "Hello World";

console.log(text.replace("World", "JavaScript"));
// "Hello JavaScript"

replaceAll() — метод, який повертає новий рядок, у якому замінено всі входження заданої підстроки. 

let text = "apple apple apple";

console.log(text.replaceAll("apple", "orange"));
// "orange orange orange"

Копіювання підрядка (slice(), substring())

slice() — метод, який повертає частину рядка між початковим та кінцевим індексами. Кінцевий індекс не включається. Метод також підтримує від'ємні індекси. 

let text = "JavaScript";

console.log(text.slice(0, 4)); // "Java"
console.log(text.slice(4));    // "Script"
console.log(text.slice(-6));   // "Script"

substring() — метод, який повертає частину рядка між двома індексами. Кінцевий індекс не включається. Від'ємні значення індексів трактуються як 0. 

let text = "JavaScript";

console.log(text.substring(0, 4));  // "Java"
console.log(text.substring(4, 10)); // "Script"

Видалення частини рядка

Рядки в JavaScript є незмінними (immutable), тому видалення частини рядка відбувається шляхом створення нового рядка без потрібних символів. Для цього можна використовувати slice(). 

let text = "Hello World";

let result = text.slice(0, 6);

console.log(result); // "Hello "
console.log(text);   // "Hello World"

Оператори (Operators)

Оператори в JavaScript — це спеціальні символи або ключові слова, які вказують комп'ютеру, яку саме дію (операцію) потрібно виконати над одним або кількома значеннями (операндами).

1. Арифметичні оператори (Arithmetic Operators)

JavaScript підтримує різні арифметичні оператори, які можуть бути використані для виконання математичних обчислень.


  • + (додавання або конкатенація рядків)
  • - (віднімання)
  • * (множення)
  • / (ділення)
  • % (статок від ділення / модуль)
  • ** (піднесення до степеня, наприклад, 2 ** 3 це 8)

Зверни увагу!

Оператор % (його називають Remainder Operator або оператором залишку від ділення) повертає залишок від цілочисельного ділення одного числа на інше. У програмуванні % обчислює саме те, що «залишилося» після того, як ми максимально поділили число.


Цей оператор часто використовують для перевірки парності числа.

2. Оператори порівняння (Comparison Operators)

Дозволяють визначати відносини між об'єктами та даними і відповідають на питання, чи вірне одне значення відносно іншого. З математики ми знаємо їх як більше та менше. Проте в JavaScript ми маємо їх дещо більше:


Оператор Назва Приклад Результат Опис
> Більше 10 > 5 true Перевіряє, чи перше значення більше за друге.
< Менше 10 < 5 false Перевіряє, чи перше значення менше за друге.
>= Більше або дорівнює 10 >= 10 true Перевіряє, чи перше значення більше або дорівнює другому.
<= Менше або дорівнює 5 <= 10 true Перевіряє, чи перше значення менше або дорівнює другому.
=== Строга рівність 5 === 5 true Перевіряє рівність значень та їхніх типів.
!== Строга нерівність 5 !== "5" true Перевіряє, чи значення або їхні типи відрізняються.
== Нестрога рівність 5 == "5" true Порівнює значення з автоматичним перетворенням типів.
!= Нестрога нерівність 5 != 10 true Перевіряє нерівність значень з можливим перетворенням типів.

Важливий нюанс:

для порівняння в JavaScript рекомендовано використовувати === та !==, а == і != застосовувати лише тоді, коли тобі потрібне автоматичне перетворення типів.

3. Логічні оператори (Logical Operators)

Логічні оператори - це оператори, які допомагають перевіряти умови та визначати, чи є вони правдивими або неправдивими.

У JavaScript є два основних логічних значення: true та false


  • && (І / AND): повертає true, якщо всі операнди істинні.
  • || (АБО / OR): повертає true, якщо хоча б один операнд істинний.
  • ! (НЕ / NOT): інвертує логічне значення (true перетворює на false і навпаки).
  • ?? (Nullish Coalescing): повертає правий операнд, якщо лівий є null або undefined.

Зверни увагу!

Логічні оператори && та || повертають одне з операндних значень залежно від результату перевірки. Оператор ! повертає логічне значення.

4. Оператори присвоєння (Assignment Operators)

Використовуються для присвоєння значень змінним.


Operator Example Equivalent Description
= x = 10 x = 10 Присвоює значення змінній
+= x += 5 x = x + 5 Додає значення до змінної
-= x -= 5 x = x - 5 Віднімає значення від змінної
*= x *= 5 x = x * 5 Множить змінну на значення
/= x /= 5 x = x / 5 Ділить змінну на значення
%= x %= 3 x = x % 3 Присвоює остачу від ділення
**= x **= 2 x = x ** 2 Підносить змінну до степеня

5. Тернарний оператор (Ternary Operator)

Тернарний оператор (?) — це скорочений спосіб запису конструкції if...else. 

condition ? expressionIfTrue : expressionIfFalse;

Приклад використання 

let age = 20;
let result = age >= 18 ? "Повнолітній" : "Неповнолітній";
console.log(result);// "Повнолітній"

Як це працює?


Якщо умова true — повертається перше значення.

Якщо умова false — повертається друге значення.

6. Унарні оператори (Unary operators)

Унарні оператори — це такі оператори в JavaScript, які працюють лише з одним операндом (одним значенням або змінною).


Унарні оператори можуть бути двох типів:


  • Передоператор (Prefix) - оператор, який розташовується перед операндом. Наприклад, ++x.
  • Постоператор (Postfix) - оператор, який розташовується після операнда. Наприклад, x++.

Унарний плюс (+)


Перетворює операнд у число, якщо це можливо. 


let num = "42";
let convertedNum = +num;
// Тепер convertedNum має тип number,
а не string.

Унарний мінус (-)


Змінює знак числа на протилежний. 


let x = 10;
let y = -x; // у містить -10.

Унарний оператор заперечення (!)


Інвертує логічне значення: перетворює true на false, а false на true. 


let isTrue = true;
let isFalse = !isTrue;
// isFalse містить false.

Інкремент (++)


Збільшує значення змінної на 1. 


let x = 5;
x++; // x містить 6.

Декремент (--)


Зменшує значення змінної на 1. 


let x = 5;
x--; // x містить 4.

Оператор typeof

Typeof - це оператор, який дозволяє визначити тип даних змінної або виразу в JavaScript. Це корисний інструмент для валідації даних та керування логікою вашого коду. 

let age = 25;
console.log(typeof age); // "number"

let name = "Josh";
console.log(typeof name); // "string"

let isStudent = true;
console.log(typeof isStudent); // "boolean"

Доречно буде сказати, що він працює як скобками, так і без. Проте при використанні () він спочатку буде виконувати код, а вже потім буде перевіряти тип результату: 

let age = 25;
console.log(typeof (age)); // "number"

Оператор delete

Delete - це оператор, який дозволяє видалити властивість об'єкта в JavaScript. Він повертає true, якщо властивість була успішно видалена, та false, якщо її видалити неможливо. 

let user = {
  name: "Josh",
  age: 25
};

delete user.age;

console.log(user); // { name: "Josh" }
console.log(user.age); // undefined

Оператор delete видаляє саме властивість об'єкта, а не сам об'єкт або змінну. Також він не видаляє елементи масиву, а лише їхні властивості, залишаючи порожнє місце.

Оператор void

Void - це оператор, який обчислює вираз та повертає undefined незалежно від результату його виконання. Він використовується, коли потрібно виконати код, але не отримувати його результат. 

let result = void (10 + 5);

console.log(result); // undefined

console.log(void 0); // undefined
console.log(void "Hello"); // undefined

Оператор void не зупиняє виконання виразу, а лише ігнорує його результат. Він може використовуватися як із дужками, так і без них. 

console.log(void (2 + 3)); // undefined

console.log(void 2 + 3); // NaN

7. Пріоритет операторів (Operator Precedence)

Operator Precedence - це порядок, у якому оператори виконуються в JavaScript. Оператори з вищим пріоритетом виконуються раніше, ніж оператори з нижчим пріоритетом. Якщо оператори мають однаковий пріоритет, порядок їх виконання залежить від асоціативності. 

let result = 2 + 3 * 4;

console.log(result); // 14

// Спочатку виконується множення (3 * 4),
// а потім додавання (2 + 12).

Дужки () дозволяють змінити стандартний порядок виконання операторів. Вираз у дужках виконується першим. 

let result = (2 + 3) * 4;

console.log(result); // 20

// Спочатку виконується додавання (2 + 3),
// а потім множення (5 * 4).

Оператори присвоєння мають нижчий пріоритет, ніж арифметичні оператори. Тому спочатку обчислюється вираз, а потім його результат присвоюється змінній. 

let x = 10 + 5 * 2;

console.log(x); // 20

// Спочатку 5 * 2 = 10
// Потім 10 + 10 = 20
// Результат присвоюється змінній x.

Якщо потрібно зробити порядок виконання більш зрозумілим, рекомендується використовувати дужки, навіть якщо вони не є обов'язковими. 

let result = 10 - 2 - 3;

console.log(result); // 5

// Оператори віднімання мають однаковий пріоритет
// і виконуються зліва направо:
// (10 - 2) - 3 = 5

Базовий синтаксис (Basic Syntax)

Синтаксис (Syntax) — це набір правил, за якими потрібно писати код певною мовою програмування.

У JavaScript синтаксис визначає:

  • як оголошувати змінні;
  • як записувати команди;
  • як використовувати оператори;
  • як оформлювати блоки коду;
  • як правильно писати функції.
const userName = "Anna";
console.log(userName);
// Приклад правильного написання.

1. Statement (інструкція) — це команда, яку JavaScript виконує.

Кожен рядок містить окрему інструкцію, по закінченню якої потрібно ставити крапку з комою (;).

JavaScript може автоматично вставляти крапки з комою (Automatic Semicolon Insertion — ASI), але рекомендується явно ставити їх наприкінці інструкцій. 

const age = 25;
let userName = "Anna";

console.log(age);
console.log(userName);

2. Expression (вираз) — це частина коду, яка обчислюється та повертає певне значення.

Приклади:

10 + 5

Результат: 15

"Hello" + " World"

Результат: "Hello World"

5 > 3

Результат: true

Вираз можна використати для присвоєння значення змінній: 

const result = 10 + 5;
console.log(result); // 15

3. Коментарі (Comments) — використовуються для пояснення коду. JavaScript не виконує їх.

Існіє однорядковий коментар // (починається з // і триває до кінця рядка) та багаторядковий коментар /* */.

4. Identifier (ідентифікатор) - це назва змінної, функції або іншого елемента в коді.

Правила створення ідентифікаторів

  1. Назва може містити літери, цифри, _ та $.
  2. Назва не може починатися з цифри.
  3. Не можна використовувати зарезервовані слова JavaScript.
  4. Назви чутливі до регістру.
  5. Назви повинні бути зрозумілими та описувати призначення елемента.

Для написання імені, яке містить декілька слів, зазвичай використовують “верблюжий регістр” (camelCase). Тобто слова йдуть одне за одним, і кожне слово пишуть із великої букви й без пробілів: myVeryLongName. Зауважте, що перше слово пишеться з маленької букви.

5. Block (блок коду) — це група інструкцій, об'єднаних фігурними дужками.

Блоки коду використовуються, зокрема, у: if...else, циклах, функціях, класах. 

if (true) {
  console.log("Hello");
  console.log("JavaScript");
}

6. Виведення інформації (Output) — для виведення інформації в консоль використовують console.log().

Можна виводити декілька значень одночасно: 

const firstName = "Anna";
const age = 25;

console.log(firstName, age); // Anna 25

7. Введення даних (Input) — для отримання інформації від користувача в браузері можна використовувати prompt(). 

const userName = prompt("Enter your name:");

console.log(userName);

Користувач вводить ім'я, після чого воно записується у змінну.

Prompt() повертає рядок (String), навіть якщо користувач вводить число, тому для перетворення рядка на число використовують Number().

Консоль (Console)

Console — це інструмент розробника, який дозволяє виводити інформацію, перевіряти результати виконання JavaScript-коду та знаходити помилки.

console.log()


Виводить інформацію в консоль.


console.log("Hello, JavaScript!");
console.log(10 + 5);

console.error()


Виводить повідомлення про помилку. 


console.error("Something went wrong!");

console.warn()


Виводить попередження.


console.warn("Be careful!");

console.info()


Виводить інформаційне повідомлення. 


console.info("Application started");

console.table()


Виводить дані у вигляді таблиці. 


const user = {
  name: "Anna",
  age: 25,
};
console.table(user);

console.clear()


Очищує консоль від повідомлень. 


console.clear();

console.group()


Групує повідомлення в консолі.


console.group("User");
console.log("Anna");
console.log(25);
console.groupEnd();

console.count()


Підраховує кількість викликів.


console.count("Click");
console.count("Click");
