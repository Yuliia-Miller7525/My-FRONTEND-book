VISUAL STUDIO CODE

a free program by Microsoft used to write, edit, and organize computer code for building websites and apps.

Найкорисніші гарячі клавіші (Shortcuts) у VS Code

Робота з кодом

Ctrl + S Зберегти файл
Ctrl + Z Скасувати дію
Ctrl + Shift + Z Повернути скасовану дію
Ctrl + X Вирізати рядок або виділений текст
Ctrl + C Копіювати рядок або текст
Ctrl + V Вставити
Alt + ↑ / ↓ Перемістити рядок вгору/вниз
Shift + Alt + ↓ Дублювати рядок вниз
Ctrl + Shift + K Видалити поточний рядок
Home / End Перейти на початок/кінець рядка

Виділення та редагування

Ctrl + D Виділити наступне входження слова
Ctrl + Shift + L Виділити всі входження слова
Alt + Click Створити додатковий курсор
Ctrl + ← / → Переміщатися між словами
Shift + Alt + ↑ / ↓ Додати курсор на рядок вище/нижче
Ctrl + / Закоментувати/розкоментувати рядок
Shift + Alt + A Блоковий коментар

Пошук і навігація

Ctrl + F Знайти текст у файлі
Ctrl + H Знайти та замінити
Ctrl + Shift + F Пошук у всьому проєкті
Ctrl + P Швидко відкрити файл
Ctrl + G Перейти до конкретного рядка
F12 Перейти до визначення класу/функції
Alt + ← Повернутися назад
Alt + → Перейти вперед

Робота з HTML, CSS та SCSS

Shift + Alt + F Форматувати документ
Ctrl + Space Викликати підказки IntelliSense
Ctrl + Shift + P Відкрити командну палітру
Ctrl + ] Збільшити відступ
Ctrl + [ Зменшити відступ
Ctrl + Enter Створити новий рядок нижче
Ctrl + Shift + Enter Створити новий рядок вище

Робота з вікнами та вкладками

Ctrl + Tab Перемикатися між файлами
Ctrl + W Закрити поточний файл
Ctrl + Shift + T Відкрити останній закритий файл
Ctrl + B Показати/сховати бокову панель
Ctrl + \ Розділити редактор
Ctrl + 1 Перейти до першого редактора
Ctrl + N Створити новий файл
