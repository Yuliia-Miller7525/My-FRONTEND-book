Closures

a function that remembers variables from its outer closures, even after the outer function has finished executing.

Замикання (Closure) — це механізм JavaScript, завдяки якому функція може запам'ятовувати змінні зі свого зовнішнього оточення та використовувати їх навіть після того, як зовнішня функція завершила своє виконання.


Простіше кажучи, функція може звертатися до змінних, які були створені поза нею, навіть якщо функція, у якій ці змінні були оголошені, вже завершила роботу. 


function outerFunction() {
  let message = "Привіт!";

  function innerFunction() {
    console.log(message);
  }

  return innerFunction;
}

const myFunction = outerFunction();

myFunction();
//Привіт!

Запам'ятай:

Коли JavaScript створює функцію, вона запам'ятовує своє лексичне оточення (Lexical Environment) — тобто має доступ до змінних, які були доступні їй під час створення.

Замикання дозволяє функції зберігати доступ до цих змінних навіть після завершення зовнішньої функції.


Де використовуються замикання?


  1. Збереження стану — наприклад, створення лічильників.
  2. Приховування даних — обмеження прямого доступу до змінних ззовні.
  3. Створення функцій із власними налаштуваннями — функції можуть запам'ятовувати передані параметри.
  4. Обробники подій — функції можуть використовувати змінні з навколишнього коду.
