Data linking and copying

зв'язування та копіювання даних

Data Linking (Зв'язування даних)


Зв'язування даних — це ситуація, коли декілька змінних посилаються на один і той самий об'єкт у пам'яті. Тобто замість створення нового об'єкта JavaScript копіює посилання на вже існуючий об'єкт. 


const user1 = {
  name: "Alex",
  age: 25,
};

const user2 = user1;

user2.age = 30;

console.log(user1.age);
// 30
console.log(user2.age);
// 30

Оскільки обидві змінні посилаються на один об'єкт, зміни через будь-яку з них будуть видимі через іншу. 


let user1 = {
  name: "Alex",
};

let user2 = user1;

user2 = {
  name: "John",
};

console.log(user1.name);
// Alex
console.log(user2.name);
// John

А це переприсвоєння змінної - user2 посилається на новий об'єкт, а user1 продовжує посилатися на початковий.

Copying Primitive Values (Копіювання примітивних значень)


Копіювання примітивних значень — це копіювання примітивного значення з однієї змінної в іншу. Коли ми присвоюємо одну змінну іншій, JavaScript копіює саме значення, а не посилання на нього. У результаті кожна змінна має власне незалежне значення. 


let firstNumber = 10;
let secondNumber = firstNumber;

secondNumber = 20;

console.log(firstNumber);
// 10
console.log(secondNumber);
// 20

Такий принцип працює з усіма примітивними типами даних (String, Boolean, Number...).


Головне, що потрібно запам'ятати:


  1. Примітивні значення копіюються незалежно одне від одного.
  2. Зміна однієї змінної не впливає на іншу.
  3. Кожна змінна зберігає власне значення.

Copying Reference Values (Копіювання посилальних значень)


Копіювання посилальних значень — це копіювання посилання на об'єкт з однієї змінної в іншу. На відміну від примітивних значень, під час присвоєння об'єкта іншій змінній JavaScript не створює його незалежну копію. Натомість копіюється посилання на той самий об'єкт. 


const user1 = {
  name: "Alex",
  age: 25,
};

const user2 = user1;

Що відбувається:


  1. Створюється об'єкт із властивостями name та age.
  2. Змінна user1 отримує посилання на цей об'єкт.
  3. Змінна user2 отримує копію цього посилання.
  4. Обидві змінні звертаються до одного об'єкта.

Якщо ми змінюємо властивість об'єкта через одну змінну, ця зміна буде доступна і через іншу. 


const user1 = {
  name: "Alex",
  age: 25,
};

const user2 = user1;

user2.name = "John";
user2.age = 30;

console.log(user1.name);
// John
console.log(user1.age);
// 30

Такий самий принцип працює і з масивами, оскільки масиви в JavaScript є об'єктами. 


const numbers1 = [1, 2, 3];

const numbers2 = numbers1;

numbers2.push(4);

console.log(numbers1);
// [1, 2, 3, 4]
console.log(numbers2);
// [1, 2, 3, 4]

Важливо пам'ятати: зміна об'єкта та переприсвоєння змінної — це різні операції. 


let user1 = {
  name: "Alex",
};

let user2 = user1;

user2 = {
  name: "John",
};

console.log(user1.name);
// Alex
console.log(user2.name);
// John

Головне, що потрібно запам'ятати:


  1. Об'єкти та масиви копіюються за посиланням.
  2. Декілька змінних можуть посилатися на один об'єкт.
  3. Зміна властивостей через одну змінну впливає на спільний об'єкт.
  4. Переприсвоєння змінної не змінює об'єкт, на який посилається інша змінна.

Shallow Copy (Поверхневе копіювання)


Поверхневе копіювання — це створення поверхневої копії об'єкта або масиву, під час якого копіюються його властивості першого рівня, але вкладені об'єкти не копіюються повністю.


Простіше кажучи, ми створюємо новий об'єкт, який має власні властивості, але вкладені об'єкти продовжують використовувати спільні посилання. 


const user1 = {
  name: "Alex",
  age: 25,
};

const user2 = { ...user1 };

user2.name = "John";

console.log(user1.name);
// Alex
console.log(user2.name);
// John

Що відбувається:


  1. Створюється початковий об'єкт user1.
  2. За допомогою оператора ... створюється його поверхнева копія user2.
  3. user1 та user2 тепер є окремими об'єктами.
  4. Зміна властивості name в user2 не впливає на user1.

Але є важливий нюанс! Якщо об'єкт містить інший об'єкт, поверхнева копія не створює незалежну копію вкладеного об'єкта. 


const user1 = {
  name: "Alex",
  address: {
    city: "Kyiv",
  },
};

const user2 = { ...user1 };

user2.name = "John";
user2.address.city = "Lviv";

console.log(user1.name);
// Alex
console.log(user1.address.city);
// Lviv

Чому так відбувається?


  • name — примітивне значення, тому воно копіюється незалежно.
  • address — вкладений об'єкт, тому копіюється лише посилання на нього.

У результаті обидва об'єкти мають власну властивість name, але посилаються на один і той самий вкладений об'єкт address.


У JavaScript є декілька способів створення поверхневих копій: Spread Operator (...), Object.assign(), slice().


Головне, що потрібно запам'ятати:


  1. Shallow Copy створює новий об'єкт або масив.
  2. Властивості першого рівня копіюються.
  3. Вкладені об'єкти не копіюються незалежно, а залишаються спільними.
  4. Найчастіше для копіювання використовують Spread Operator (...)..

Важливий момент: поверхневе копіювання — це не те саме, що звичайне присвоєння. 


const user2 = user1;
// Копіюється посилання

const user3 = { ...user1 };
// Створюється новий об'єкт

Deep Copy (Глибоке копіювання)


Глибоке копіювання — це створення повністю незалежної копії об'єкта або масиву, включно з усіма вкладеними об'єктами та масивами.


Простіше кажучи, на відміну від Shallow Copy, глибоке копіювання створює копії не лише зовнішнього об'єкта, а й вкладених структур. 


const user1 = {
  name: "Alex",
  age: 25,
  address: {
    city: "Kyiv",
  },
};

const user2 = structuredClone(user1);

У цьому прикладі:


  1. Створюється початковий об'єкт user1.
  2. Метод structuredClone() створює його глибоку копію.
  3. Властивості та вкладені об'єкти копіюються незалежно.
  4. Зміни в user2 не впливають на user1.

const user1 = {
  name: "Alex",
  age: 25,
  address: {
    city: "Kyiv",
  },
};

const user2 = structuredClone(user1);

user2.name = "John";
user2.address.city = "Lviv";

console.log(user1.name);
// Alex
console.log(user1.address.city);
// Kyiv

console.log(user2.name);
// John
console.log(user2.address.city);
// Lviv

Спосіб глибокого копіювання — structuredClone() - вбудований метод JavaScript, який створює глибоку копію значення.


Синтаксис: 
const copy = structuredClone(original);

Де:
- original — початковий об'єкт або масив.
- copy — нова незалежна копія.

Метод підтримує багато типів даних, зокрема вкладені об'єкти, масиви, Date, Map, Set та інші.


Важливо: structuredClone() не підтримує всі можливі типи значень. Наприклад, функції та DOM-вузли не можна клонувати цим методом — буде помилка DataCloneError.
