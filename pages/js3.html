Loops

are statements that allow a program to repeat a block of code as long as a condition is met

Цикли — це конструкції програмування, які дозволяють багаторазово виконувати певний блок коду, поки виконується задана умова або протягом певної кількості повторень.


Цикли дозволяють:


  • повторювати виконання коду без його дублювання;
  • перебирати елементи масивів;
  • виконувати операції з даними;
  • автоматизувати повторювані завдання.

Приклад без циклу
                
console.log("Hello!");
console.log("Hello!");
console.log("Hello!");
console.log("Hello!");
console.log("Hello!");
//У цьому випадку ми 5 разів пишемо однаковий код.

Приклад із циклом

for (let i = 0; i < 5; i++) {
  console.log("Hello!");
}
//Hello!
  Hello!
  Hello!
  Hello!
  Hello!

Висновок: цикл дозволяє виконати одну й ту саму дію п'ять разів, використовуючи лише одну конструкцію.

1. The for loop

Цикл for - повторює виконання блоку коду, поки задана умова залишається істинною. Він складається з трьох частин: ініціалізації, умови та зміни значення лічильника.


Синтаксис: 
for (initialization; condition; update) {
  // Code to execute
}

Розберемо кожен елемент:

initialization - створення та початкове значення лічильника.

condition - визначає, чи потрібно виконувати цикл.

update - змінює значення лічильника після кожного повторення.

{ } - блок коду, який виконується повторно. 


for (let i = 0; i < 5; i++) {
  console.log(i);
}
//0
  1
  2
  3
  4

Розберемо по кроках:

let i = 0 - створюється змінна i зі значенням 0.

i < 5 - перевіряється, чи менше значення i за 5.

Якщо умова true, виконується console.log(i).

i++ - значення i збільшується на 1.

Цикл повертається до перевірки умови.

Коли i стає 5, умова i < 5 повертає false , і цикл завершується.


Важливо: ініціалізація виконується лише один раз. Умова перевіряється перед кожним повторенням, а update виконується після тіла циклу.


Коли ми використовуємо цикл for?


  1. відома кількість повторень;
  2. необхідно працювати з лічильником;
  3. потрібно перебрати індекси масиву;
  4. потрібно виконати певну кількість математичних операцій.

2. The while loop

Цикл while - виконує блок коду доти, доки задана умова є істинною (true).


Синтаксис: 
while (condition) {
  // Code to execute
}

Розберемо кожен елемент:

condition - умова, яка перевіряється перед виконанням тіла циклу.

Якщо умова true, код виконується.

Якщо умова false, цикл не виконується або завершується. 


let i = 0;

while (i < 5) {
  console.log(i);
  i++;
}
//0
  1
  2
  3
  4

Розберемо по кроках:

Створюємо змінну i зі значенням 0.

Перевіряємо умову i < 5.

Якщо вона істинна, виводимо значення i.

Збільшуємо i на 1.

Знову перевіряємо умову.

Коли i дорівнює 5, цикл завершується.


Коли ми використовуємо цикл while?


  1. кількість повторень заздалегідь невідома;
  2. виконання залежить від певної умови;
  3. потрібно повторювати операцію, поки не настане певна подія.

3. The do...while loop

Цикл do...while - виконує блок коду щонайменше один раз, а потім перевіряє умову. Якщо умова істинна, виконання повторюється.


Синтаксис: 
do {
  // Code to execute
} while (condition);

Основна відмінність: у do...while перевірка умови відбувається після виконання тіла циклу. 


let i = 0;

do {
  console.log(i);
  i++;
} while (i < 5);
//0
  1
  2
  3
  4

Коли ми використовуємо цикл while?


  1. Коли потрібно виконати код хоча б один раз.
  2. Коли потрібно показати меню користувачу, а потім перевірити, чи потрібно повторити.
  3. Коли потрібно спочатку виконати дію, а потім перевірити результат.

4. The for...of loop

Цикл for...of - перебирає значення елементів ітерованих об'єктів, наприклад масивів та рядків.


Синтаксис: 
for (const element of iterable) {
  // Code to execute
}

Розберемо кожен елемент:

const element - змінна, яка отримує поточне значення елемента.

of - ключове слово, яке використовується для перебору значень.

iterable - об'єкт, значення якого перебираються. завершується.

{ } - тіло циклу. завершується. 


const fruits = ["Apple", "Banana", "Orange"];

for (const fruit of fruits) {
  console.log(fruit);
}
//Apple
  Banana
  Orange

Розберемо по кроках:

fruits — масив, який містить три елементи.

fruit — змінна, яка отримує значення поточного елемента.

Під час першого повторення fruit дорівнює "Apple".

Під час другого повторення fruit дорівнює "Banana".

Під час третього повторення fruit дорівнює "Orange".

Після перебору всіх елементів цикл завершується.


Перевага: for...of дозволяє перебирати значення без необхідності вручну створювати лічильник.

5. The for...in loop

Цикл for...in - перебирає ключі (назви властивостей) об'єкта.


Синтаксис: 
for (const key in object) {
  // Code to execute
}

const user = {
  name: "Alex",
  age: 25,
  city: "Kyiv"
};

for (const key in user) {
  console.log(key);
}
//name
  age
  city

Якщо потрібно отримати не лише ключі, а й значення властивостей, використовуємо квадратні дужки: 


const user = {
  name: "Alex",
  age: 25,
  city: "Kyiv"
};

for (const key in user) {
  console.log(user[key]);
}
//Alex
  25
  Kyiv

for...in призначений переважно для перебору властивостей об'єктів. Для масивів зазвичай краще використовувати for...of, якщо потрібні значення елементів.

6. Loop control — Керування циклами

break - негайно завершує виконання поточного циклу. 


for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }

  console.log(i);
}
//1
  2
  3
  4



continue - пропускає поточну ітерацію циклу та переходить до наступного повторення. 


for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}
//1
  2
  4
  5



return - завершує виконання функції, а не просто цикл. 


function findNumber() {
  for (let i = 1; i <= 10; i++) {
    if (i === 5) {
      return i;
    }
  }
}

console.log(findNumber());
//5

7. Nested loops — Вкладені цикли

Вкладений цикл - це цикл, розташований усередині іншого циклу. 


for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 2; j++) {
    console.log(`i: ${i}, j: ${j}`);
  }
}
//i: 1, j: 1
  i: 1, j: 2
  i: 2, j: 1
  i: 2, j: 2
  i: 3, j: 1
  i: 3, j: 2

Розберемо по кроках:

Зовнішній цикл i виконується 3 рази.

Внутрішній цикл j виконується 2 рази для кожного повторення зовнішнього циклу.

Загальна кількість виконань console.log() — 6.


Коли ми використовуємо nested loops?


  1. Для перебору двовимірних масивів.
  2. Для створення таблиць.
  3. Для роботи з матрицями.
  4. Для порівняння елементів різних колекцій.

7. Infinite loops — Нескінченні цикли

Нескінченний цикл - Нескінченний цикл 


let i = 0;

while (i < 5) {
  console.log(i);
}

Розберемо по кроках:

У цьому коді відсутній оператор i++.

i завжди дорівнює 0;

умова i < 5 завжди true;

цикл не завершується.


Як уникнути infinite loops?


  1. Переконайся, що умова циклу може стати false.
  2. Перевір, чи змінюється лічильник.
  3. Переконайся, що змінна оновлюється правильно.
  4. Не забувай про break, якщо цикл має завершитися за певної умови.
