1. Вбудовані функції (Built-in Functions)

У JavaScript є три вбудовані функції, які дозволяють взаємодіяти з користувачем через прості браузерні вікна:


  • alert() — показує повідомлення.
  • prompt() — запитує інформацію в користувача.
  • confirm() — запитує підтвердження дії.

Вони належать до об'єкта window, тому можна писати як window.alert(), так і просто alert().

alert(message)

Функція alert() виводить невелике модальне вікно з повідомленням і кнопкою OK.


Синтаксис: 
alert(message);

alert("Привіт! Ласкаво просимо на сайт!");

//Коли браузер виконає цей код,
користувач побачить повідомлення
та зможе натиснути OK.


let userName = "Олена";

alert("Привіт, " + userName + "!");
//Результат:
браузер покаже повідомлення
Привіт, Олена!.

АБО

let age = 25;

alert(`Тобі ${age} років!`);
//Результат:
браузер покаже повідомлення
Тобі 25 років!

prompt(message, default)

Функція prompt() відкриває вікно з текстом, полем для введення інформації та кнопками OK і Cancel.


Синтаксис: 
prompt(message, default);      
де default — значення, яке буде попередньо записане в поле введення (необов'язковий параметр).           
            

let userName = prompt("Як тебе звати?");

alert(`Привіт, ${userName}!`);

// Це працює таким чином,
що спочатку браузер запитує ім'я,
користувач вводить, наприклад, Олена,
значення зберігається в змінній userName,
а alert() показує привітання.


let city = prompt("У якому місті ти живеш?",
"Київ");

alert(`Ти живеш у місті ${city}`);

//Тут у полі введення вже буде написано «Київ»,
але користувач зможе змінити це значення.

Що повертає prompt()?


  • Натиснув OK — введений текст (тип String).
  • Натиснув OK, нічого не ввів — Порожній рядок "".
  • Натиснув Cancel — null.

confirm(question)

Функція confirm() показує вікно з повідомленням і двома кнопками: OK та Cancel.


Синтаксис: 
confirm(question);      
question — запитання, на яке користувач має відповісти,
а повертає булеве значення: true або false.      
            

let answer = confirm("Хочеш видалити цей файл?");

console.log(answer);
//Результат:
  Натиснув OK → true.
  Натиснув Cancel → false.


let answer = confirm("Ти хочеш продовжити?");

if (answer === true) {
    alert("Продовжуємо!");
} else {
    alert("Дію скасовано.");
}
//Тут:
  Якщо користувач натисне OK — 
  побачить «Продовжуємо!».
  Якщо натисне Cancel — 
  побачить «Дію скасовано».

2. Стрілкові функції (Arrow Functions)

Стрілкова функція (Arrow Function) — це коротший спосіб записати функцію в JavaScript. 


Звичайна функція:
function sayHello() {
  console.log("Hello!");
}

sayHello();

Стрілкова функція:
const sayHello = () => {
  console.log("Hello!");
};

sayHello();

Результат в обох випадках:
//Hello!

Розбираємо синтаксис:


  • const — створюємо змінну.
  • sayHello — назва функції.
  • = — присвоюємо функцію змінній.
  • () — місце для параметрів.
  • => — стрілка, яка позначає стрілкову функцію.
  • {} — тіло функції.
  • console.log() — команда, яка виконується.

Важливо: стрілкова функція — це функція, яку ми присвоюємо змінній.

Стрілкові функції з параметрами 


Звичайна функція:
function greet(name) {
  console.log(`Привіт, ${name}!`);
}

greet("Оля");

Стрілкова функція:
const greet = (name) => {
  console.log(`Привіт, ${name}!`);
};

greet("Оля");

Результат в обох випадках:
//Привіт, Оля!

Важливо: якщо параметр один — дужки можна прибрати, але якщо параметрів два або більше, дужки обов'язкові. Якщо ж параметрів немає, круглі дужки також обов'язкові.

Скорочений запис: implicit return


Це одна з найважливіших особливостей стрілкових функцій. Якщо функція виконує лише одну дію та повертає результат, можна прибрати фігурні дужки {} і слово return. 


Звичайний запис:
const sum = (a, b) => {
  return a + b;
};

console.log(sum(5, 3));

Скорочений запис:
const sum = (a, b) => a + b;

console.log(sum(5, 3));

Результат однаковий:
//8

Важливо: коли всередині функції декілька команд - не можна використовувати скорочений запис. Фігурні дужки потрібні, тому що ми виконуємо декілька дій. 


const calculate = (a, b) => {
  const result = a + b;
  console.log("Результат:");

  return result;
};

Є ще один нюанс: якщо хочемо повернути об'єкт, його потрібно взяти в круглі дужки. Інакше JavaScript може сприйняти {} як тіло функції, а не як об'єкт. 


const createUser = () => 
({ name: "Anna", age: 25 });

Чим Arrow Function відрізняється від звичайної функції?


Звичайна функція Стрілкова функція
Має власний this. Не має власного this, а використовує його із зовнішньої області видимості.
Можна використовувати оператор new для створення об'єктів. Не можна використовувати оператор new.
Function Declaration можна викликати до місця її оголошення завдяки hoisting. Стрілкову функцію, записану через const або let, не можна викликати до її ініціалізації.
Має власний об'єкт arguments. Не має власного arguments.
Може бути звичайною функцією-конструктором. Не може бути функцією-конструктором.

3. Анонімні функції (Anonymous Functions)

Анонімна функція (Anonymous Function) — це функція, яка не має власного імені. 


function() {
  console.log("Привіт!");
}

Важливо: у такому вигляді ми не можемо просто оголосити її окремою інструкцією, як звичайну Function Declaration. Анонімні функції зазвичай використовуються як частина іншого виразу: наприклад, присвоюються змінній або передаються в іншу функцію.


Найпоширеніший спосіб використання анонімної функції — через Function Expression (функціональний вираз). 


const sayHello = function() {
  console.log("Привіт!");
};

sayHello();

Зверни увагу: хоча функція не має власного імені, ми все одно можемо її викликати через змінну, якій її присвоїли.

Передавання анонімної функції як аргументу


Анонімні функції також можна передавати безпосередньо в інші функції як аргументи. 


setTimeout(function() {
  console.log("Привіт через 2 секунди!");
}, 2000);

Що тут відбувається?


  • setTimeout() — вбудована функція JavaScript, яка виконує передану функцію після певної затримки.
  • function() { ... } — анонімна функція, яку ми передаємо як аргумент.
  • 2000 — час затримки в мілісекундах (2 секунди).

Тобто ми не створюємо окрему змінну для функції, а одразу передаємо її туди, де вона потрібна.

Для чого використовують анонімні функції?


  • функцію не потрібно використовувати багато разів у різних місцях програми;
  • потрібно передати функцію як аргумент іншій функції;
  • потрібно передати функцію як аргумент іншій функції;
  • потрібно виконати невелику дію без створення окремої іменованої функції.
