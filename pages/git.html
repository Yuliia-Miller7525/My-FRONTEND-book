Git & GitHub

a version control system that helps developers track changes in their code, save different versions of a project, and go back to previous versions when needed.

Важливо розрізняти:

Git

Система контролю версій

Працює локально

Відстежує зміни

GitHub

Онлайн-платформа

Зберігає віддалені репозиторії

Допомагає зберігати та поширювати код

Для початку роботи з Git, його потрібно завантажити. Потім перевіряємо встановлення у терміналі безпосередньо комп'ютерного пристрою або у VS Code за допомогою команди git --version.
