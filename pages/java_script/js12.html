prototypes

objects that allow other objects to inherit properties and methods in JavaScript

Прототип (prototypes) — це об'єкт, від якого інший об'єкт може успадковувати властивості та методи. Якщо JavaScript не знаходить властивість або метод в об'єкті, він шукає їх у його прототипі. 


const user = {
  name: "Anna",
};

console.log(user.toString());

Метод toString() не створений
у самому об'єкті user.
Він успадковується від Object.prototypes.

Основне, що потрібно запам'ятати:


  1. Об'єкти можуть успадковувати властивості та методи.
  2. У кожного звичайного об'єкта є прототип.
  3. Якщо властивість не знайдена в об'єкті, JavaScript шукає її в прототипі.

Ланцюжок прототипів (prototypes Chain) — це послідовність об'єктів, через які JavaScript шукає потрібну властивість або метод, якщо не знаходить їх у самому об'єкті.


Як це працює:


  1. JavaScript шукає властивість у самому об'єкті.
  2. Якщо не знаходить — шукає в його прототипі.
  3. Якщо не знаходить і там — переходить до наступного прототипу.
  4. Пошук завершується, коли JavaScript доходить до null.

const user = {
  name: "Anna",
  age: 25,
};

console.log(user.toString());

Методу toString() немає
в об'єкті user, тому
JavaScript шукає його в
прототипі Object.prototypes і знаходить.

Схема ланцюжка:


user

name, age

↓

Object.prototypes

toString(), valueOf() та інші методи

↓

null

Кінець ланцюжка прототипів

__proto__ — це спосіб отримати доступ до прототипу об'єкта або змінити його. 


const user = {
  name: "Anna",
};

console.log(user.__proto__);

У консолі побачимо прототип об'єкта user — Object.prototype.


Важливо: __proto__ — це застарілий спосіб доступу до прототипу. Замість нього рекомендується використовувати Object.getPrototypeOf().

Метод Object.getPrototypeOf() - це вбудований метод JavaScript, який повертає прототип вказаного об'єкта. Object.getPrototypeOf().


Синтаксис: 
Object.getPrototypeOf(object);

const user = {
  name: "Anna",
};

const prototype = Object.getPrototypeOf(user);

console.log(prototype);
//Object.prototype

Запам'ятай:


  • __proto__ — доступ до прототипу через властивість.
  • Object.getPrototypeOf() — рекомендований спосіб отримати прототип об'єкта.

Object.setPrototypeOf() — це метод, який дозволяє встановити або змінити прототип об'єкта.


Синтаксис: 
Object.setPrototypeOf(object, prototype);

const animal = {
  eat: function () {
    console.log("Тварина їсть");
  },
};

const dog = {
  bark: function () {
    console.log("Гав-гав!");
  },
};

Object.setPrototypeOf(dog, animal);

dog.eat();
// Тварина їсть
dog.bark();
// Гав-гав!


Ми встановили об'єкту dog прототип animal.

Важливо: цей метод корисний для навчання та окремих випадків, але в реальному коді краще встановлювати прототип під час створення об'єкта, а не змінювати його пізніше.

Object.create() — це метод, який створює новий об'єкт із вказаним прототипом.


Синтаксис: 
Object.create(prototype);

Тут prototype — об'єкт,
який стане прототипом нового об'єкта.

const animal = {
  eat: function () {
    console.log("Тварина їсть");
  },
};

const dog = Object.create(animal);

dog.bark = function () {
  console.log("Гав-гав!");
};

dog.eat();
// Тварина їсть
dog.bark();
// Гав-гав!

Що відбулося?


  1. Ми створили об'єкт animal із методом eat().
  2. За допомогою Object.create(animal) створили новий об'єкт dog.
  3. Об'єкт animal став прототипом об'єкта dog.
  4. Тому dog може використовувати метод eat(), хоча він не створений безпосередньо в ньому. 

Перевіримо прототип:

console.log(Object.getPrototypeOf(dog) === animal);
// true

Власні та успадковані властивості (Own and Inherited Properties)

В JavaScript властивості об'єктів поділяються на два види:


  • Власні властивості (Own Properties) — властивості, які створені безпосередньо в самому об'єкті.
  • Успадковані властивості (Inherited Properties) — властивості, які об'єкт отримує від свого прототипу. 

const animal = {
  eat: function () {
    console.log("Тварина їсть");
  },
};

const dog = Object.create(animal);

dog.name = "Rex";

Для перевірки використовують два способи:


  1. Object.hasOwn() — перевіряє, чи є властивість власною властивістю об'єкта. 

    2. console.log(Object.hasOwn(dog, "name"));
// true

console.log(Object.hasOwn(dog, "eat"));
// false

  2. Оператор in — перевіряє, чи існує властивість в об'єкті або в його ланцюжку прототипів. 

    3. console.log("name" in dog);
// true

console.log("eat" in dog);
// true

Прототипування (Prototyping)

prototype — це властивість функції-конструктора, яка визначає прототип для об'єктів, створених за допомогою цієї функції та оператора new.


Простіше кажучи, ми можемо додати метод до prototype, і всі об'єкти, створені цим конструктором, зможуть його використовувати. 


function Animal(name) {
  this.name = name;
}

// Додаємо метод до prototype
Animal.prototype.sayHello = function () {
  console.log(`Привіт! Я ${this.name}`);
};

// Створюємо об'єкти
const dog = new Animal("Rex");
const cat = new Animal("Murka");

dog.sayHello();
// Привіт! Я Rex
cat.sayHello();
// Привіт! Я Murka

Як це працює?


  1. Створюємо функцію-конструктор Animal.
  2. Додаємо метод sayHello() до Animal.prototype.
  3. За допомогою new створюємо об'єкти dog і cat.
  4. Обидва об'єкти отримують доступ до методу sayHello() через свій прототип. 

Перевіримо прототип:
                
console.log(
  Object.getPrototypeOf(dog) === Animal.prototype
);
// true


constructor — це властивість прототипу, яка містить посилання на функцію-конструктор, що створила об'єкт. 


function User(name) {
  this.name = name;
}

const user = new User("Anna");

console.log(user.constructor === User);
// true

Як це працює?


  1. Ми створили функцію-конструктор User.
  2. Створили об'єкт user за допомогою new.
  3. Об'єкт user успадкував властивість constructor від User.prototype.
  4. Ця властивість посилається на функцію User.

Важливо розуміти, що constructor зазвичай знаходиться не в самому об'єкті, а в його прототипі. 


function User(name) {
  this.name = name;
}

const user = new User("Anna");

console.log(user.constructor);
// User

console.log(Object.hasOwn(user, "constructor"));
// false

console.log(Object.hasOwn(User.prototype, "constructor"));
// true

Також властивість constructor можна змінити. Наприклад, якщо ми повністю замінимо прототип. Це відбувається тому, що під час заміни прототипу ми втратили його початкову властивість constructor. 


function User(name) {
  this.name = name;
}

User.prototype = {
  sayHello: function () {
    console.log("Hello!");
  },
};

const user = new User("Anna");

console.log(user.constructor === User);
// false


Її можна відновити:
User.prototype.constructor = User;

console.log(user.constructor === User); // true

Що варто запам'ятати?


  • constructor — властивість прототипу, яка зазвичай посилається на функцію-конструктор.
  • Об'єкти можуть успадковувати цю властивість через прототип.
  • Її можна змінити або втратити під час заміни прототипу.
  • constructor не створює об'єкти — для цього використовується оператор new разом із функцією-конструктором.


instanceof — це оператор, який перевіряє, чи є об'єкт екземпляром певної функції-конструктора або класу. Повертає результат true або false.


Синтаксис: 
object instanceof Constructor;

object — об'єкт, який перевіряємо.
Constructor —функція-конструктор або клас.

function User(name) {
  this.name = name;
}

const user = new User("Anna");

console.log(user instanceof User);
// true
console.log(user instanceof Object);
// true
console.log(user instanceof Array);
// false

Важливі особливості


  • instanceof перевіряє весь ланцюжок прототипів, а не тільки безпосередній прототип.
  • Оператор повертає тільки true або false.
  • instanceof не створює об'єкт, а лише перевіряє його прототипний ланцюжок. 

Ще один приклад:
                
function Animal() {}

function Dog() {}

Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

const dog = new Dog();

console.log(dog instanceof Dog);
// true
console.log(dog instanceof Animal);
// true
console.log(dog instanceof Object);
// true

Об'єкт dog є екземпляром Dog,
але також проходить перевірку Animal та Object,
оскільки їхні прототипи присутні
в його прототипному ланцюжку.
