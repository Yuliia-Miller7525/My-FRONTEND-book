Object Methods

functions stored as object properties that define what an object can do

Object Methods — це функції, які є властивостями об'єкта та описують дії, які цей об'єкт може виконувати. Простіше кажучи: вони виконують певні дії з інформацією про об'єкт або інші дії. 


const user = {
  name: "Anna",
  age: 25,

  sayHello: function () {
    console.log("Hello!");
  },
};

Щоб викликати метод, використовуємо крапку та круглі дужки: user.sayHello();.


У JavaScript метод можна створити так само, як і звичайну властивість об'єкта. Різниця полягає в тому, що значенням методу є функція.


Звичайний синтаксис: 
sayHello: function() {}

Скорочений синтаксис: 
sayHello() {}

const user = {
  name: "Anna",

  sayHello: function () {
    console.log("Hello!");
  },
};

Або

const user = {
  name: "Anna",

  sayHello() {
    console.log("Hello!");
  },
};

Після створення методу ми можемо викликати його, щоб виконати код, який знаходиться всередині функції. Для виклику методу використовуємо назву об'єкта, крапку (.), назву методу та круглі дужки (()).


Синтаксис: 
objectName.methodName();

const user = {
  name: "Anna",

  sayHello() {
    console.log("Hello!");
  },
};

user.sayHello();
//Hello!

Вбудовані статичні методи об'єкта Object (Built-in Static Object Methods)

Static Methods — це методи, які викликаються безпосередньо через назву об'єкта Object, а не через створений користувацький об'єкт.


Object.keys()

Метод Object.keys() повертає масив із назвами (ключами) власних перелічуваних властивостей об'єкта.


Синтаксис: 
Object.keys(object);

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const keys = Object.keys(user);

console.log(keys);
//["name", "age", "city"]

Object.values()

Метод Object.values() повертає масив зі значеннями власних перелічуваних властивостей об'єкта.


Синтаксис: 
Object.values(object);

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const values = Object.values(user);

console.log(values);
//["Anna", 25, "Kyiv"]

Object.entries()

Метод Object.entries() повертає масив пар [ключ, значення] для кожної власної перелічуваної властивості об'єкта.


Синтаксис: 
Object.entries(object);

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const entries = Object.entries(user);

console.log(entries);
//[
  ["name", "Anna"],
  ["age", 25],
  ["city", "Kyiv"]
  ]

Object.assign()

Метод Object.assign() копіює власні перелічувані властивості з одного або декількох об'єктів до цільового об'єкта.


Синтаксис: 
Object.assign(target, source);

target — цільовий об'єкт, у який копіюються властивості.

source — об'єкт, властивості якого потрібно скопіювати. 


const user = {
  name: "Anna",
  age: 25,
};

const additionalInfo = {
  city: "Kyiv",
};

Object.assign(user, additionalInfo);

console.log(user);
//{
  name: "Anna",
  age: 25,
  city: "Kyiv"
  }

Object.hasOwn()

Метод Object.hasOwn() перевіряє, чи має об'єкт власну властивість із зазначеним ім'ям.


true — якщо властивість існує безпосередньо в об'єкті.

false — якщо такої власної властивості немає.


Синтаксис: 
Object.hasOwn(object, property);

object — об'єкт, який перевіряємо.

property — назва властивості. 


const user = {
  name: "Anna",
  age: 25,
};

console.log
(Object.hasOwn(user, "name"));
console.log
(Object.hasOwn(user, "email"));
//true
  false
