Basics of classes (Основи класів)

Class — це шаблон для створення об'єктів, який описує їхні властивості та методи.


Простіше кажучи, клас — це шаблон, за яким можна створювати багато схожих об'єктів із різними значеннями властивостей.


Наприклад, ми можемо створити клас User, який описуватиме користувача. А потім на його основі створити декількох користувачів із різними іменами та віком. 


class User {
  // Властивості та методи класу
}

Класи допомагають:


  • Створювати багато однотипних об'єктів.
  • Об'єднувати властивості та методи в одному місці.
  • Повторно використовувати код.
  • Організовувати код і робити його зрозумілішим.

Для створення класу використовується ключове слово class, після якого вказується назва класу. 


class User {
  name = "Anna";
  age = 25;

  sayHello() {
    console.log(`Hello, my name is ${this.name}`);
  }
}

Щоб створити об'єкт на основі класу, використовується оператор new. 


class User {
  name = "Anna";
  age = 25;

  sayHello() {
    console.log(`Hello, my name is ${this.name}`);
  }
}

const user1 = new User();
const user2 = new User();

user1.sayHello();
// Hello, my name is Anna


user1 та user2 —
це окремі екземпляри класу User.

Конструктор класу (Constructor)

Конструктор (constructor) — це спеціальний метод класу, який автоматично викликається під час створення нового екземпляра класу за допомогою оператора new.


Його основне завдання — встановити початкові значення властивостей нового об'єкта.


Синтаксис: 
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}


constructor — спеціальний метод,
який викликається під час створення об'єкта.

name та age — параметри,
які отримує конструктор.

this.name та this.age — властивості
нового об'єкта.

this — посилається на
конкретний екземпляр класу.

Щоб передати значення конструктору, використовуємо оператор new: 


class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna", 25);
const user2 = new User("John", 30);

console.log(user1.name);
// Anna
console.log(user2.name);
// John

Важливо запам'ятати


  1. У класі може бути лише один метод constructor.
  2. Конструктор автоматично викликається під час створення об'єкта через new.
  3. Якщо конструктор не вказати, JavaScript автоматично створить порожній конструктор.
  4. Конструктор не потрібно викликати вручну.

class Car {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

const car1 = new Car("BMW", 2020);
const car2 = new Car("Audi", 2023);

console.log(car2.brand)
//Audi


class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna", 25);
const user2 = new User("John", 30);

console.log(user1.age + user2.age);
//55


class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna");

console.log(user1.name);
console.log(user1.age);
//Anna
//undefined


А як зробити, щоб вік за замовчуванням дорівнював 18?
                
class User {
  constructor(name, age = 18) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna");

console.log(user1.age);
// 18

Властивості класу (Class Properties)

Властивості класу (Properties) — це змінні, які зберігають дані об'єктів, створених на основі класу.


У JavaScript є два основні способи оголошення властивостей класу: через конструктор та безпосередньо в класі. 


Властивості через конструктор
                
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna", 25);

console.log(user1.name);
// Anna
console.log(user1.age);
// 25

Тут властивості створюються всередині
конструктора за допомогою this.
Значення передаються під час створення об'єкта.


Властивості безпосередньо в класі
                
class User {
  name = "Anna";
  age = 25;
}

const user1 = new User();

console.log(user1.name);
// Anna
console.log(user1.age);
// 25

У цьому випадку властивості
отримують значення безпосередньо
під час створення екземпляра класу.

Ці два способи можна поєднувати в одному класі. 


class User {
  role = "user";

  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}

const user1 = new User("Anna", 25);

console.log(user1.name);
// Anna
console.log(user1.role);
// user


class Car {
  wheels = 4;

  constructor(brand) {
    this.brand = brand;
  }
}

const car1 = new Car("BMW");
const car2 = new Car("Audi");

console.log(car1.wheels);
//4
console.log(car2.brand);
//Audi

Методи класу (Class Methods)

Методи класу (Methods) — це функції, які визначають дії, доступні об'єктам, створеним на основі класу.


Синтаксис: 
class Car {
  drive() {
    console.log("Автомобіль їде");
  }

  stop() {
    console.log("Автомобіль зупинився");
  }
}

Щоб викликати метод, спочатку потрібно створити екземпляр класу: 


const car1 = new Car();

car1.drive();
// Автомобіль їде
car1.stop();
// Автомобіль зупинився

Методи класу можуть звертатися до властивостей конкретного об'єкта за допомогою this. 


class Car {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }

  showInfo() {
    console.log(`Марка: ${this.brand}, рік: ${this.year}`);
  }
}

const car1 = new Car("BMW", 2020);
const car2 = new Car("Audi", 2023);

car1.showInfo();
// Марка: BMW, рік: 2020
car2.showInfo();
// Марка: Audi, рік: 2023

Зверни увагу: ми створили один метод showInfo(), але він працює з даними різних об'єктів.

Геттери та сеттери (Getters and Setters)

Геттери (Getters) та сеттери (Setters) — це спеціальні методи, які дозволяють отримувати та змінювати значення властивостей об'єкта.


  • get — отримує значення властивості.
  • set — встановлює або змінює значення властивості.


Геттер дозволяє отримати значення властивості, використовуючи синтаксис звернення до властивості. 


class User {
  constructor(name) {
    this.name = name;
  }

  get userName() {
    return this.name;
  }
}

const user1 = new User("Anna");

console.log(user1.userName);
// Anna

Перед назвою методу використовується get. Ми звертаємося до нього як до властивості — user1.userName, без круглих дужок.



Сеттер дозволяє змінювати значення властивості. 


class User {
  constructor(name) {
    this.name = name;
  }

  set userName(newName) {
    this.name = newName;
  }
}

const user1 = new User("Anna");

user1.userName = "Maria";

console.log(user1.name);
// Maria

Сеттер викликається через звичайне присвоєння, без круглих дужок.



Звичайні властивості дозволяють безпосередньо отримувати та змінювати дані, але не контролюють, які саме значення ми записуємо. Саме тут нам допомагають сеттери та геттери.


Сеттер дозволяє перевіряти значення перед тим, як записати його у властивість, а геттер дозволяє визначити, яке значення повертатиметься під час звернення до властивості. Найчастіше їх використовують разом.


Наприклад, ми хочемо заборонити від'ємний вік: 


class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  get age() {
    return this._age;
  }

  set age(value) {
    if (value >= 0) {
      this._age = value;
    } else {
      console.log("Вік не може бути від'ємним!");
    }
  }
}

const user1 = new User("Anna", 25);

console.log(user1.age);
// 25

user1.age = 30;

console.log(user1.age);
// 30

user1.age = -5;
// Вік не може бути від'ємним!

console.log(user1.age);
// 30

Статичні властивості та методи (Static Properties and Methods)

Статичні властивості та методи — це властивості й методи, які належать самому класу, а не його окремим екземплярам. Для їх оголошення використовується ключове слово static.


Статичний метод можна викликати без створення екземпляра класу. 


class User {
  static sayHello() {
    console.log("Привіт!");
  }
}

User.sayHello();
// Привіт!

Якщо спробувати викликати цей метод через екземпляр класу, отримаємо помилку: 


const user1 = new User();

user1.sayHello();
// Помилка

Так само можна створювати статичні властивості: 


class User {
  static role = "Administrator";
}

console.log(User.role);
// Administrator

Статичні методи зручно використовувати для дій, які не залежать від конкретного екземпляра класу. Наприклад, можна створити метод для перевірки віку: 


class User {
  static isAdult(age) {
    return age >= 18;
  }
}

console.log(User.isAdult(25));
// true
console.log(User.isAdult(15));
// false


class Car {
  static wheels = 4;

  constructor(brand) {
    this.brand = brand;
  }

  showBrand() {
    console.log(this.brand);
  }

  static showWheels() {
    console.log(Car.wheels);
  }
}

const car1 = new Car("BMW");

car1.showBrand();
// BMW
Car.showWheels();
// 4

Статичні властивості та методи використовують, коли певні дані або дії стосуються всього класу, а не окремого об'єкта. Наприклад:


  • Зберігання загальної інформації про клас.
  • Перевірка даних.
  • Виконання допоміжних обчислень.
  • Створення методів, для роботи яких не потрібен конкретний екземпляр.

Наслідування (Inheritance)

Наслідування (Inheritance) — це механізм, який дозволяє одному класу отримувати властивості та методи іншого класу.


Простіше кажучи, ми можемо створити один основний клас, а потім на його основі створювати інші класи, які використовуватимуть його властивості та методи.


Уявімо, що ми створюємо програму для роботи з транспортними засобами. У нас є автомобіль і мотоцикл. Обидва транспортні засоби мають: марку (brand), рік випуску (year), метод показу інформації (showInfo()). Ми могли б окремо описати всі ці властивості та методи в кожному класі. Але це призвело б до повторення коду. Натомість можна створити загальний клас Vehicle, а від нього успадкувати класи Car та Motorcycle. 


Це батьківський клас,
який містить спільні властивості та методи.
                
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }

  showInfo() {
    console.log(`Марка: ${this.brand}, рік: ${this.year}`);
  }
}

Для наслідування використовується ключове слово extends. 


class Car extends Vehicle {

}


class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }

  showInfo() {
    console.log(`Марка: ${this.brand}, рік: ${this.year}`);
  }
}

class Car extends Vehicle {

}

const car1 = new Car("BMW", 2020);

car1.showInfo();

// Марка: BMW, рік: 2020

Зверни увагу:
ми не створювали конструктор у класі Car,
але змогли передати значення brand та year.
Це тому, що дочірній клас успадкував
конструктор батьківського класу.

Що дає наслідування?


  • Дозволяє повторно використовувати готовий код.
  • Допомагає уникати дублювання властивостей та методів.
  • Дозволяє створювати більш спеціалізовані класи на основі загальних.

Ключове слово super

super — це ключове слово, яке дозволяє дочірньому класу звертатися до конструктора та методів батьківського класу. Воно використовується під час наслідування (extends).


Уявімо, що ми маємо батьківський клас Vehicle та дочірній клас Car. Батьківський клас зберігає марку автомобіля, а дочірній повинен додатково зберігати кількість дверей. 


class Vehicle {
  constructor(brand) {
    this.brand = brand;
  }
}

class Car extends Vehicle {
  constructor(brand, doors) {
    super(brand);
    this.doors = doors;
  }
}

const car1 = new Car("BMW", 4);

console.log(car1.brand);
// BMW
console.log(car1.doors);
// 4

Розберімо цей приклад:


  1. Створюємо дочірній клас Car, який успадковує Vehicle.
  2. У конструкторі Car використовуємо super(brand).
  3. super(brand) викликає конструктор батьківського класу Vehicle і передає йому значення brand.
  4. Батьківський конструктор записує значення у this.brand.
  5. Далі дочірній клас створює власну властивість this.doors.

Важливо запам'ятати: якщо дочірній клас має власний конструктор, то перед використанням this необхідно викликати super(). Без цього JavaScript видасть помилку.



super можна використовувати не тільки для виклику конструктора, а й для звернення до методів батьківського класу. 


class Animal {
  makeSound() {
    console.log("Тварина видає звук");
  }
}

class Dog extends Animal {
  makeSound() {
    super.makeSound();

    console.log("Собака гавкає");
  }
}

const dog1 = new Dog();

dog1.makeSound();
//Тварина видає звук
  Собака гавкає

Коротко про super


  • super() - викликає конструктор батьківського класу
  • super.method() - викликає метод батьківського класу

Приватні властивості та методи (Private Properties and Methods)

Приватні властивості (Private Properties) — це властивості класу, до яких не можна отримати прямий доступ за межами цього класу.


Для створення приватних властивостей використовується символ # перед назвою властивості. 


class User {
  #password;

  constructor(name, password) {
    this.name = name;
    this.#password = password;
  }
}

const user1 = new User("Anna", "12345");

console.log(user1.name);
// Anna
console.log(user1.#password);
// Помилка

Важливо: приватні властивості не можна просто прочитати або змінити через зовнішній об'єкт.


Якщо нам усе-таки потрібно отримати доступ до приватної властивості - можна створити звичайний метод класу: 


class User {
  #password;

  constructor(name, password) {
    this.name = name;
    this.#password = password;
  }

  showPassword() {
    return this.#password;
  }
}

const user1 = new User("Anna", "12345");

console.log(user1.showPassword());
// 12345

Так само, як властивості, методи також можуть бути приватними. Для цього перед назвою методу ставиться #. 


class User {
  #showMessage() {
    console.log("Це приватний метод");
  }

  sayHello() {
    this.#showMessage();
  }
}

const user1 = new User();

user1.sayHello();
// Це приватний метод
