Spread & Rest operators

to expand elements & to collect elements

У JavaScript є два оператори, які використовують однаковий синтаксис — три крапки (...).


Spread Operator — розгортає елементи масиву або властивості об'єкта.


Rest Operator — збирає декілька елементів або аргументів в один масив.

1. Spread Operator


Spread Operator дозволяє розгорнути елементи масиву або властивості об'єкта в окремі значення. 


const numbers = [1, 2, 3];

console.log(...numbers);
//1 2 3

Тут оператор ... розгорнув масив numbers на окремі елементи. 


Без Spread:
console.log(numbers);
//[1, 2, 3]

З Spread:
console.log(...numbers);
//1 2 3

Отже, Spread дозволяє працювати з елементами масиву окремо, а не передавати весь масив як одне значення.


За допомогою Spread можна створити копію масиву, не змінюючи оригінал. 


const numbers = [1, 2, 3];

const copiedNumbers = [...numbers];

console.log(copiedNumbers);
// [1, 2, 3]

Чому не можна просто написати const copiedNumbers = numbers? Тому що в такому випадку ми не створюємо копію, а передаємо посилання на той самий масив. 


const numbers = [1, 2, 3];

const copiedNumbers = numbers;

copiedNumbers.push(4);

console.log(numbers);
// [1, 2, 3, 4]

Змінилася також початкова змінна numbers.


А якщо використати Spread:
                
const numbers = [1, 2, 3];

const copiedNumbers = [...numbers];

copiedNumbers.push(4);

console.log(numbers);       // [1, 2, 3]
console.log(copiedNumbers); // [1, 2, 3, 4]

Spread дозволяє об'єднати декілька масивів в один. 


const firstArray = [1, 2, 3];
const secondArray = [4, 5, 6];

const result = [...firstArray, ...secondArray];

console.log(result);
// [1, 2, 3, 4, 5, 6]

За допомогою Spread можна створити новий масив із додатковими елементами. 


const numbers = [1, 2, 3];

const newNumbers = [...numbers, 4, 5];

console.log(newNumbers);
// [1, 2, 3, 4, 5]

Важливо запам'ятати: Spread створює новий масив, але це поверхнева копія (Shallow Copy). Якщо всередині масиву є вкладені масиви або об'єкти, вони продовжують використовувати спільні посилання.



За допомогою Spread можна створити копію об'єкта. 


const user = {
  name: "Anna",
  age: 25,
};

const copiedUser = { ...user };

console.log(copiedUser);
//{
  name: "Anna",
  age: 25
  }

Якщо змінити властивість нового об'єкта, початковий об'єкт залишиться незмінним: 


copiedUser.age = 30;

console.log(user.age);
// 25
console.log(copiedUser.age);
// 30

Spread дозволяє об'єднати властивості декількох об'єктів в один. 


const userInfo = {
  name: "Anna",
  age: 25,
};

const userAddress = {
  city: "Kyiv",
  country: "Ukraine",
};

const user = {
  ...userInfo,
  ...userAddress,
};

console.log(user);
//{
  name: "Anna",
  age: 25,
  city: "Kyiv",
  country: "Ukraine"
  }

За допомогою Spread можна створити новий об'єкт і змінити окремі його властивості. 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const updatedUser = {
  ...user,
  age: 26,
};

console.log(updatedUser);
//{
  name: "Anna",
  age: 26,
  city: "Kyiv"
  }

Невелике уточнення: копіювання об'єктів через Spread також є поверхневим (Shallow Copy). Вкладені об'єкти не копіюються окремо.



Spread Operator дозволяє передавати елементи масиву у функцію як окремі аргументи. 


Без Spread:
                
function calculateSum(a, b, c) {
  return a + b + c;
}

const numbers = [10, 20, 30];

console.log(calculateSum(numbers));

Результат буде не таким,
як ми очікуємо,
оскільки функція отримує
весь масив як один аргумент.


З використанням Spread:
                
function calculateSum(a, b, c) {
  return a + b + c;
}

const numbers = [10, 20, 30];

console.log(calculateSum(...numbers));
// 60

Тут ...numbers розгортає масив
і передає його елементи окремо

Spread особливо корисний із вбудованими математичними функціями. Наприклад, Math.max() знаходить найбільше число серед переданих аргументів, а Math.min() — найменше. 


const numbers = [10, 5, 25, 3, 15];

console.log(Math.max(...numbers));
// 25
console.log(Math.min(...numbers));
// 3

Spread можна використовувати під час виклику функції, щоб передати елементи масиву як окремі аргументи - functionName(...array);.

2. Rest Operator


Rest Operator також записується за допомогою трьох крапок (...), але виконує протилежну дію до Spread.


Rest найчастіше використовують у функціях, коли заздалегідь невідомо, скільки аргументів буде передано. 


function showNumbers(...numbers) {
  console.log(numbers);
}

showNumbers(10, 20, 30, 40);
//[10, 20, 30, 40]

Оскільки Rest збирає аргументи в масив, ми можемо використовувати методи масивів для роботи з ними. 


function calculateSum(...numbers) {
  return numbers.reduce(function (sum, number) {
    return sum + number;
  }, 0);
}

console.log(calculateSum(10, 20, 30));
// 60
console.log(calculateSum(5, 15));
// 20

Rest можна використовувати разом зі звичайними параметрами функції. 


function showUserInfo(name, age, ...hobbies) {
  console.log(`Ім'я: ${name}`);
  console.log(`Вік: ${age}`);
  console.log(`Хобі: ${hobbies}`);
}

showUserInfo
("Anna", 25, "books", "music", "trips");
//Ім'я: Anna
  Вік: 25
  Хобі: books,music,trips

Важливе правило: Rest завжди повинен бути останнім параметром функції. 


Правильно:
function example(a, b, ...rest) {}

Неправильно:
function example(...rest, a, b) {}

Rest Operator можна використовувати не лише у функціях, а й під час деструктуризації масивів та об'єктів. Його завдання залишається таким самим — зібрати всі елементи, які залишилися, в одну змінну. Під час деструктуризації масиву можна отримати окремі елементи, а решту зібрати за допомогою Rest. 


const numbers = [10, 20, 30, 40, 50];

const [first, second, ...rest] = numbers;

console.log(first);
// 10
console.log(second);
// 20
console.log(rest);
// [30, 40, 50]

Можна також пропустити непотрібні елементи: 


const numbers = [10, 20, 30, 40, 50];

const [first, , third, ...rest] = numbers;

console.log(first);
// 10
console.log(third);
// 30
console.log(rest);
// [40, 50]

З об'єктами Rest працює схожим чином: ми можемо отримати окремі властивості, а всі інші зібрати в новий об'єкт. 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
  country: "Ukraine",
};

const { name, age, ...rest } = user;

console.log(name);
// "Anna"
console.log(age);
// 25
console.log(rest);
//{
  city: "Kyiv",
  country: "Ukraine"
  }
