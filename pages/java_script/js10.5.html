Destructuring

a way to unpack values from arrays or properties from objects into separate variables

Деструктуризація — це спосіб витягувати значення з масивів або властивості з об'єктів і записувати їх в окремі змінні.


Простіше кажучи, замість того щоб окремо звертатися до кожного елемента масиву або властивості об'єкта, ми можемо отримати їх одразу за допомогою спеціального синтаксису. 


Без деструктуризації:

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const name = user.name;
const age = user.age;
const city = user.city;

console.log(name);
// Anna
console.log(age);
// 25
console.log(city);
// Kyiv


З деструктуризацією:
                
const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const { name, age, city } = user;

console.log(name);
// Anna
console.log(age);
// 25
console.log(city);
// Kyiv

Види деструктуризації:


  1. Array Destructuring — деструктуризація масивів.
  2. Object Destructuring — деструктуризація об'єктів.

1. Array Destructuring


Array Destructuring — це спосіб отримувати значення з масиву та записувати їх в окремі змінні.


Головна особливість: значення присвоюються змінним за порядком розташування елементів у масиві.


Для деструктуризації масивів використовуються квадратні дужки []. 


const numbers = [10, 20, 30];

const [first, second, third] = numbers;

console.log(first);
// 10
console.log(second)
// 20
console.log(third);
// 30

Зверни увагу: назви змінних ми обираємо самостійно. Важливий саме порядок.



Ми не зобов'язані отримувати всі елементи масиву. Якщо певне значення нам не потрібне, його можна пропустити, залишивши порожнє місце між комами. 


const colors = ["red", "green", "blue"];

const [first, , third] = colors;

console.log(first);
// red
console.log(third);
// blue

Важливо: коми визначають позиції елементів, тому їх не можна прибирати, якщо потрібно пропустити значення.



Якщо в масиві немає значення для певної змінної, їй можна призначити значення за замовчуванням. Для цього використовується оператор =. 


const numbers = [10, 20];

const [first, second, third = 30] = numbers;

console.log(first);
// 10
console.log(second);
// 20
console.log(third);
// 30

Зверни увагу: значення за замовчуванням використовується тільки тоді, коли значення відсутнє (undefined).



Деструктуризація дозволяє легко поміняти значення двох змінних місцями без створення додаткової змінної. 


let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a);
// 20
console.log(b);
// 10

2. Object Destructuring


Object Destructuring — це спосіб отримувати значення властивостей об'єкта та записувати їх в окремі змінні.


На відміну від масивів, де значення отримуються за порядком, в об'єктах ми звертаємося до властивостей за їхніми назвами (ключами).


Для деструктуризації об'єктів використовуються фігурні дужки {}. 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const { name, age, city } = user;

console.log(name);
// Anna
console.log(age);
// 25
console.log(city);
// Kyiv

Зверни увагу: назви змінних за замовчуванням повинні збігатися з назвами властивостей об'єкта.



На відміну від деструктуризації масивів, порядок змінних в об'єкті не має значення. 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

const { city, name, age } = user;

console.log(city);
// Kyiv
console.log(name);
// Anna
console.log(age);
// 25

JavaScript знаходить потрібні значення за назвами властивостей, а не за їхнім порядком.



Ми можемо отримувати лише ті властивості об'єкта, які нам потрібні. Не обов'язково деструктуризувати весь об'єкт. 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
  country: "Ukraine",
};

const { name, age } = user;

console.log(name);
// Anna
console.log(age);
// 25


Під час деструктуризації об'єктів ми можемо присвоїти властивості іншу назву змінної. Для цього використовується двокрапка :. 


const user = {
  name: "Anna",
  age: 25,
};

const { name: userName, age: userAge } = user;

console.log(userName);
// Anna
console.log(userAge);
// 25

Якщо об'єкт не містить певної властивості або її значення дорівнює undefined, ми можемо встановити значення за замовчуванням. Для цього використовується оператор =. 


const user = {
  name: "Anna",
  age: 25,
};

const { name, age, city = "Kyiv" } = user;

console.log(name);
// Anna
console.log(age);
// 25
console.log(city);
// Kyiv

Зверни увагу: якщо властивість існує та має значення null, значення за замовчуванням не застосовується. 


const user = {
  city: null,
};

const { city = "Kyiv" } = user;

console.log(city);
// null

3. Nested Destructuring


Nested Destructuring (Вкладена деструктуризація) — це спосіб отримувати значення з об'єктів або масивів, які знаходяться всередині інших об'єктів або масивів.


Якщо один об'єкт знаходиться всередині іншого, ми можемо отримати його властивості за допомогою вкладеної деструктуризації. 


const user = {
  name: "Anna",
  age: 25,
  address: {
    city: "Kyiv",
    country: "Ukraine",
  },
};

const {
  address: { city, country },
} = user;

console.log(city);
// Kyiv
console.log(country);
// Ukraine

Синтаксис: 
const {
  address: { city, country },
} = user;

Тут ми не створюємо змінну address, а одразу отримуємо city та country.


Якщо нам потрібна також змінна address, її можна додати окремо:


Синтаксис: 
const {
  address,
  address: { city, country },
} = user;

Так само можна отримувати значення з масивів, які знаходяться всередині інших масивів. 


const numbers = [10, [20, 30], 40];

const [first, [second, third], fourth] = numbers;

console.log(first);
// 10
console.log(second);
// 20
console.log(third);
// 30
console.log(fourth);
// 40

Можна також використовувати деструктуризацію об'єктів і масивів одночасно. 


const user = {
  name: "Anna",
  scores: [90, 85, 100],
};

const {
  name,
  scores: [firstScore, secondScore, thirdScore],
} = user;

console.log(name);
// Anna
console.log(firstScore);
// 90
console.log(secondScore);
// 85
console.log(thirdScore);
// 100
