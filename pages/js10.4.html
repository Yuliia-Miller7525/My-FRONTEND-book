Array Methods

built-in functions used to work with and manipulate arr-methods

Методи масивів (Array Methods) — це вбудовані функції JavaScript, які дозволяють працювати з масивами: додавати, видаляти, знаходити, змінювати та обробляти їхні елементи. 


const fruits = ["apple", "banana"];

fruits.push("orange");

console.log(fruits);
// ["apple", "banana", "orange"]

Важливо: методи масивів викликаються через крапку після назви масиву.


Два важливі типи методів


Mutating methods — змінюють початковий масив.

Non-mutating methods — не змінюють початковий масив, а повертають новий масив або інше значення.

1. Методи додавання та видалення елементів масиву


push()


додає один або декілька елементів у кінець масиву


Синтаксис: 
array.push(element1, element2, ...);

Приклад: 
const fruits = ["apple", "banana"];

fruits.push("orange");

console.log(fruits);
// ["apple", "banana", "orange"]

pop()


видаляє останній елемент масиву


Синтаксис: 
array.pop();

Приклад: 
const fruits = ["apple", "banana", "orange"];

fruits.pop();

console.log(fruits);
// ["apple", "banana"]

unshift()


додає один або декілька елементів на початок масиву


Синтаксис: 
array.unshift(element1, element2, ...);

Приклад: 
const fruits = ["banana", "orange"];

fruits.unshift("apple");

console.log(fruits);
// ["apple", "banana", "orange"]

shift()


видаляє перший елемент масиву


Синтаксис: 
array.shift();

Приклад: 
const fruits = ["apple", "banana", "orange"];

fruits.shift();

console.log(fruits);
// ["banana", "orange"]

splice()


дозволяє додавати, видаляти та замінювати елементи масиву за їхніми індексами.


Синтаксис: 
array.splice(start, deleteCount, item1, item2, ...);

  • start - індекс, з якого починається зміна масиву
  • deleteCount - кількість елементів, які потрібно видалити
  • item1, item2... - елементи, які потрібно додати

Приклад видалення: 
const fruits = ["apple", "banana", "orange", "kiwi"];

fruits.splice(1, 2);

console.log(fruits);
// ["apple", "kiwi"]

Приклад додавання: 
const fruits = ["apple", "orange"];

fruits.splice(1, 0, "banana");

console.log(fruits);
// ["apple", "banana", "orange"]

Приклад заміни: 
const fruits = ["apple", "banana", "orange"];

fruits.splice(1, 1, "kiwi");

console.log(fruits);
// ["apple", "kiwi", "orange"]

slice()


повертає новий масив, який містить вибрані елементи початкового масиву


Синтаксис: 
array.slice(start, end);

  • start - індекс, з якого починається вибірка
  • end - індекс, до якого виконується вибірка (не включно)

Приклад: 
const fruits = ["apple", "banana", "orange", "kiwi"];

const result = fruits.slice(1, 3);

console.log(result);
// ["banana", "orange"]

console.log(fruits);
// ["apple", "banana", "orange", "kiwi"]

Якщо не передавати параметри, slice() поверне копію всього масиву.

concat()


об'єднує два або більше масивів або додає окремі значення та повертає новий масив


Синтаксис: 
array.concat(value1, value2, ...);

Приклад: 
const fruits = ["apple", "banana"];
const vegetables = ["carrot", "potato"];

const result = fruits.concat(vegetables);

console.log(result);
// ["apple", "banana", "carrot", "potato"]

2. Методи пошуку елементів масиву


indexOf()


повертає індекс першого елемента масиву, який відповідає заданому значенню


Синтаксис: 
array.indexOf(searchElement, fromIndex);

  • searchElement - елемент, який потрібно знайти
  • fromIndex - індекс, з якого починається пошук (необов'язковий)

Приклад: 
const fruits = ["apple", "banana", "orange", "kiwi"];

const result = fruits.indexOf("orange");

console.log(result);
// 2

Якщо елемент не знайдений: 
const fruits = ["apple", "banana", "orange"];

const result = fruits.indexOf("kiwi");

console.log(result);
// -1

lastIndexOf()


повертає індекс останнього елемента масиву, який відповідає заданому значенню


Синтаксис: 
array.lastIndexOf(searchElement, fromIndex);

Приклад: 
const numbers = [10, 20, 30, 20, 40];

const result = numbers.lastIndexOf(20);

console.log(result);
// 3

includes()


перевіряє, чи містить масив певний елемент


Синтаксис: 
array.includes(searchElement, fromIndex);

Приклад: 
const fruits = ["apple", "banana", "orange"];

console.log(fruits.includes("banana"));
// true

console.log(fruits.includes("kiwi"));
// false

Перевірка з певного індексу: 
const numbers = [10, 20, 30, 40];

console.log(numbers.includes(20, 2));
// false

find()


шукає перший елемент масиву, який відповідає заданій умові, та повертає цей елемент


Синтаксис: 
array.find(function(element, index, array) {
  return condition;
});

Приклад:

Шукаємо перше число, яке більше за 10: 

const numbers = [5, 8, 12, 15, 20];

const result = numbers.find(function(number) {
  return number > 10;
});

console.log(result);
// 12

Якщо елемент не знайдений: 
const numbers = [2, 4, 6, 8];

const result = numbers.find(function(number) {
  return number > 10;
});

console.log(result);
// undefined

findIndex()


шукає перший елемент масиву, який відповідає заданій умові, та повертає його індекс


Синтаксис: 
array.findIndex(function(element, index, array) {
  return condition;
});

Приклад: 
const numbers = [5, 8, 12, 15, 20];

const result = numbers.findIndex(function(number) {
  return number > 10;
});

console.log(result);
// 2

Якщо елемент не знайдений: 
const numbers = [2, 4, 6, 8];

const result = numbers.findIndex(function(number) {
  return number > 10;
});

console.log(result);
// -1

findLast()


повертає останній елемент, який відповідає заданій умові


Приклад: 
const numbers = [5, 12, 8, 15, 20];

const result = numbers.findLast(function(number) {
  return number > 10;
});

console.log(result);
// 20


findLastIndex()


повертає індекс останнього елемента, який відповідає заданій умові


Приклад: 
const numbers = [5, 12, 8, 15, 20];

const result = numbers.findLastIndex(function(number) {
  return number > 10;
});

console.log(result);
// 4

3. Методи перебору масивів


3.1 Метод forEach()


forEach() — перебирає всі елементи масиву та виконує задану функцію для кожного з них.


Синтаксис: 
array.forEach(function(element, index, array) {
  // дія з кожним елементом
});

const fruits = ["apple", "banana", "orange"];

fruits.forEach(function(fruit) {
  console.log(fruit);
});
// apple
// banana
// orange

Якщо потрібно отримати не тільки елемент, а й його індекс, можна використати другий параметр: 


const fruits = ["apple", "banana", "orange"];

fruits.forEach(function(fruit, index) {
  console.log(`${index}: ${fruit}`);
});
// 0: apple
// 1: banana
// 2: orange

Важлива особливість - метод forEach() не повертає новий. масив. 


const numbers = [1, 2, 3];

const result = numbers.forEach(function(number) {
  return number * 2;
});

console.log(result);
// undefined

3.2 Метод map()


map() — перебирає всі елементи масиву, виконує задану функцію для кожного елемента та повертає новий масив із результатами її виконання.


Синтаксис: 
array.map(function(element, index, array) {
  return newValue;
});

const numbers = [1, 2, 3, 4];

const result = numbers.map(function(number) {
  return number * 2;
});

console.log(result);
// [2, 4, 6, 8]

console.log(numbers);
// [1, 2, 3, 4]


const names = ["anna", "alex", "maria"];

const result = names.map(function(name) {
  return name.toUpperCase();
});

console.log(result);
// ["ANNA", "ALEX", "MARIA"]


const users = [
  { name: "Anna", age: 20 },
  { name: "Alex", age: 25 },
  { name: "Maria", age: 30 }
];

const names = users.map(function(user) {
  return user.name;
});

console.log(names);
// ["Anna", "Alex", "Maria"]

3.3 Метод filter()


filter() — перебирає елементи масиву та повертає новий масив, який містить лише ті елементи, що відповідають заданій умові.


Синтаксис: 
array.filter(function(element, index, array) {
  return condition;
});

Знайдемо всі числа, більші за 10: 
const numbers = [5, 8, 12, 15, 20];

const result = numbers.filter(function(number) {
  return number > 10;
});

console.log(result);
// [12, 15, 20]

Знайдемо користувачів, яким більше ніж 25 років: 
const users = [
  { name: "Anna", age: 20 },
  { name: "Alex", age: 25 },
  { name: "Maria", age: 30 },
  { name: "John", age: 35 }
];

const result = users.filter(function(user) {
  return user.age > 25;
});

console.log(result);
//[
  { name: "Maria", age: 30 },
  { name: "John", age: 35 }
  ]

Якщо жоден елемент не відповідає умові: 
const numbers = [1, 2, 3, 4];

const result = numbers.filter(function(number) {
  return number > 10;
});

console.log(result);
// []

Важлива особливість:


У map(): return визначає, яке значення потрапить до нового масиву.

У filter(): return визначає, чи потрапить елемент до нового масиву.

У forEach(): return не створює результат для самого методу.

4. Перетворення та обробка масивів


4.1 Метод reduce()


reduce() — перебирає елементи масиву та послідовно об'єднує їхні значення в один результат.


Його можна використовувати для:


  1. Обчислення суми чисел.
  2. Обчислення середнього значення.
  3. Підрахунку кількості елементів.
  4. Об'єднання даних.
  5. Створення об'єктів або інших структур даних.

Основні особливості:


  1. Не змінює початковий масив сам по собі.
  2. Повертає одне підсумкове значення.
  3. Приймає callback-функцію.
  4. Може приймати початкове значення акумулятора.

Синтаксис: 
array.reduce(function(accumulator, currentValue, index, array) {
  return newValue;
}, initialValue);

Розберемо параметри:


  1. accumulator - зберігає результат попередньої ітерації
  2. currentValue - поточний елемент масиву
  3. index - індекс поточного елемента
  4. array - початковий масив
  5. initialValue - початкове значення акумулятора, з якого починається робота reduce()

Головне, що потрібно зрозуміти: reduce() бере попередній результат, додає до нього наступний елемент і зберігає новий результат в акумуляторі. 


const numbers = [1, 2, 3, 4];

const result = numbers.reduce
(function(accumulator, currentValue) {
  return accumulator + currentValue;
}, 0);

console.log(result);
// 10

Важливо: початкове значення не є обов'язковим параметром, але його використання зазвичай рекомендоване, оскільки робить поведінку методу більш передбачуваною.


4.2 Метод reduceRight()


reduceRight() — працює так само, як reduce(), але перебирає елементи масиву справа наліво. 


const numbers = [1, 2, 3, 4];

const result = numbers.reduceRight
(function(accumulator, currentValue) {
  return accumulator - currentValue;
});

console.log(result);
// -2

4.3 Метод flat()


flat() — створює новий масив, у якому вкладені масиви розгортаються на один або декілька рівнів. Простіше кажучи, він дозволяє об'єднати вкладені масиви в один звичайний масив.


Синтаксис: 
array.flat(depth);
Де:
- depth — кількість рівнів вкладеності, які потрібно розгорнути.
- За замовчуванням depth дорівнює 1.

const numbers = [1, 2, [3, 4], 5];

const result = numbers.flat();

console.log(result);
// [1, 2, 3, 4, 5]


const numbers = [1, 2, [3, 4, [5, 6]]];

const result = numbers.flat(2);

console.log(result);
// [1, 2, 3, 4, 5, 6]


const numbers = [1, [2, [3, [4, [5]]]]];

const result = numbers.flat(Infinity);

console.log(result);
// [1, 2, 3, 4, 5]

Infinity означає, що потрібно розгорнути всі рівні вкладеності незалежно від їхньої кількості.


Важливі особливості:


  1. flat() повертає новий масив і не змінює початковий.
  2. За замовчуванням розгортає лише один рівень вкладеності.
  3. Можна вказати потрібну глибину за допомогою depth.
  4. Також метод видаляє порожні елементи масиву на рівнях, які розгортає.

4.4 Метод flatMap()


flatMap() — поєднує можливості двох методів: map() та flat():


  1. Перебирає кожен елемент масиву та виконує над ним певну операцію (як map()).
  2. Об'єднує отримані вкладені масиви в один масив (як flat()).

Простіше кажучи, flatMap() дозволяє одночасно перетворити елементи масиву та розгорнути результат на один рівень вкладеності.


Синтаксис: 
array.flatMap(function (element) {
  // код перетворення
  return result;
});
Де:
- element — поточний елемент масиву.
- return — значення або масив,
який потрібно повернути після обробки елемента.

const numbers = [1, 2, 3];

const result = numbers.flatMap(function (number) {
  return [number, number * 2];
});

console.log(result);
// [1, 2, 2, 4, 3, 6]


const users = ["Anna", "Alex"];

const result = users.flatMap(function (user) {
  return [user, user.length];
});

console.log(result);
// ["Anna", 4, "Alex", 4]

Метод flatMap() також можна використовувати для відбору елементів. 


const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers.flatMap(function (number) {
  if (number % 2 === 0) {
    return [number];
  }

  return [];
});

console.log(result);
// [2, 4, 6]

Як це працює?


  • Якщо число парне, повертаємо масив із цим числом.
  • Якщо число непарне, повертаємо порожній масив.
  • flatMap() об'єднує результати в один масив.

Важливі особливості:


  1. flatMap() не змінює початковий масив.
  2. Повертає новий масив.
  3. Розгортає результат лише на один рівень вкладеності.
  4. Не приймає аргумент depth, на відміну від flat().
