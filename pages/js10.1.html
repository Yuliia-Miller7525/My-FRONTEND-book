Objects

collections of key-value pairs used to store related data

1. Основи об'єктів

об'єкт — це тип даних, який дозволяє зберігати декілька пов'язаних між собою значень у вигляді пар ключ — значення (key — value). 


const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
  email: "anna@gmail.com",
};

У цьому прикладі:


  • user — назва змінної, у якій зберігається об'єкт.
  • name, age, city, email — ключі (keys).
  • "Anna", 25, "Kyiv", "anna@gmail.com" — значення (values).
  • Кожна пара ключ — значення називається властивістю об'єкта (property).

Важливо: значення властивостей можуть мати різні типи даних: рядки, числа, логічні значення, масиви, інші об'єкти та навіть функції. А ключі об'єктів у JavaScript можуть бути рядками або символами (Symbol). Якщо ми записуємо ключ без лапок, JavaScript сприймає його як назву властивості та автоматично перетворює на рядок (якщо це звичайний ідентифікатор).


Літерал об'єкта — це спосіб створення об'єкта за допомогою фігурних дужок {}.


Синтаксис: 
const objectName = {
  key1: value1,
  key2: value2,
  key3: value3,
};

const user = {
  name: "Anna",
  age: 25,
  isStudent: true,
};

Є декілька важливих правил, які потрібно запам'ятати:


  1. Кожна властивість складається з ключа та значення.
  2. Між ключем і значенням ставимо двокрапку :.
  3. Різні властивості відокремлюємо комами ,.
  4. Назви ключів зазвичай записуємо без лапок, якщо це коректні ідентифікатори.
  5. Якщо назва ключа містить пробіли або спеціальні символи, використовуємо лапки. 

const user = {
  name: "Anna",
  age: 25,
  "home city": "Kyiv",
  "favorite-color": "blue",
};

Найчастіше об'єкти оголошують через const. Але тут є важливий нюанс - const забороняє повторно присвоювати змінній інше значення, але не забороняє змінювати властивості самого об'єкта. 


const user = {
  name: "Anna",
  age: 25,
};

user.age = 26; // Можна змінити

console.log(user.age); // 26

А ось так робити не можна:

const user = {
  name: "Anna",
};

user = {
  name: "Maria",
}; // Помилка!

У JavaScript існує два основні способи доступу до властивостей об'єкта:


  1. Через крапку (Dot Notation).
  2. Через квадратні дужки (Bracket Notation).


Доступ через крапку (Dot Notation) - це найпростіший і найпоширеніший спосіб отримання значення властивості.


Синтаксис: 
objectName.propertyName;

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

console.log(user.name); // Anna
console.log(user.age); // 25
console.log(user.city); // Kyiv

Доступ через квадратні дужки (Bracket Notation) - це другий спосіб отримання значення властивості.


Синтаксис: 
objectName["propertyName"];

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

console.log(user["name"]); // Anna
console.log(user["age"]); // 25
console.log(user["city"]); // Kyiv

Коли використовувати крапку, а коли квадратні дужки?


Dot Notation (.) Bracket Notation ([])
Ключ записуємо без лапок Ключ записуємо в лапках або використовуємо змінну
Підходить для звичайних назв властивостей Підходить для будь-яких рядкових ключів
Не підтримує динамічні ключі Підтримує динамічні ключі


Якщо ми спробуємо отримати властивість, якої немає в об'єкті, JavaScript не видасть помилку. Він поверне undefined (означає, що значення не було визначене.).


Якщо всередині об'єкта є інший об'єкт, ми можемо отримувати доступ до його властивостей через декілька крапок. 


const user = {
  name: "Anna",
  address: {
    city: "Kyiv",
    street: "Shevchenka",
  },
};

console.log(user.address.city);
// Kyiv
console.log(user.address.street);
// Shevchenka

2. Додавання, зміна та видалення властивостей об'єкта (Adding, Updating and Deleting Properties)

Щоб додати нову властивість до об'єкта, достатньо звернутися до неї через крапку або квадратні дужки та присвоїти значення за допомогою =. 


const user = {
  name: "Anna",
  age: 25,
};

// Додаємо нову властивість
user.city = "Kyiv";

console.log(user);

Результат:
{
  name: "Anna",
  age: 25,
  city: "Kyiv"
}


const user = {
  name: "Anna",
};

user["email"] = "anna@gmail.com";

console.log(user.email);
// anna@gmail.com


Важливо:
якщо властивості з таким ключем ще немає,
JavaScript створить її автоматично.


Якщо властивість уже існує, ми можемо змінити її значення за допомогою оператора присвоєння =. 


const user = {
  name: "Anna",
  age: 25,
};

user.age = 26;

console.log(user.age); // 26


Для видалення властивості з об'єкта використовують оператор delete.


Синтаксис: 
delete objectName.propertyName;

const user = {
  name: "Anna",
  age: 25,
  city: "Kyiv",
};

// Видаляємо властивість city
delete user.city;

console.log(user);

Результат:
{
  name: "Anna",
  age: 25
}

Важливо: оператор delete видаляє саме властивість об'єкта, а не змінну, у якій зберігається об'єкт.
