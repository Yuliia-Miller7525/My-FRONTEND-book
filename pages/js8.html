Higher-Order Functions

functions that take other functions as arguments or return functions as their results.

Функції вищого порядку (Higher-Order Functions) — це функції, які можуть виконувати одну з двох дій:

  1. Приймати іншу функцію як аргумент.
  2. Повертати іншу функцію як результат своєї роботи.

Тобто функція вищого порядку — це функція, яка працює з іншими функціями.

Функція, яка приймає іншу функцію як аргумент


JavaScript дозволяє передавати одну функцію в іншу так само, як ми передаємо числа, рядки або інші значення. 


function sayHello() {
  console.log("Привіт!");
}

function executeFunction(callback) {
  callback();
}

executeFunction(sayHello);
//Привіт!

Розберімо цей приклад поетапно.


  1. Створюємо звичайну функцію:

    2. function sayHello() {
  console.log("Привіт!");
}

    Функція sayHello() просто виводить повідомлення в консоль.


  2. Створюємо функцію, яка приймає іншу функцію: 

    3. function executeFunction(callback) {
  callback();
}

    Тут, executeFunction — функція, яка приймає іншу функцію, callback — параметр, у який передається функція, callback() — виклик функції, яку ми отримали через параметр.


  3. Передаємо функцію як аргумент:

    4. executeFunction(sayHello);

    Ми передаємо sayHello без круглих дужок, тому що нам потрібно передати саму функцію, а не викликати її одразу.


    Коли виконується executeFunction(sayHello), відбувається таке:


    1. Функція sayHello передається в executeFunction.
    2. Параметр callback отримує цю функцію.
    3. Усередині executeFunction виконується callback().
    4. Викликається функція sayHello, яка виводить повідомлення.

Запам'ятай різницю

Без дужок — передаємо функцію.

З дужками — викликаємо функцію.

Функції зворотного виклику (Callback higher-order)


Callback Function (функція зворотного виклику) — це функція, яку передають як аргумент іншій функції, щоб вона могла бути викликана всередині неї. 


function greet() {
  console.log("Доброго дня!");
}

function processUser(callback) {
  callback();
}

processUser(greet);

У цьому прикладі:


  • processUser() — функція вищого порядку (Higher-Order Function).
  • greet() — функція зворотного виклику (Callback Function).
  • callback — параметр, через який передається функція.

Тобто одна функція може бути функцією вищого порядку, а інша — функцією зворотного виклику.

Функція, яка повертає іншу функцію


Другий варіант функції вищого порядку — це функція, яка не приймає іншу функцію, а створює та повертає її 


function createGreeting() {
  return function () {
    console.log("Привіт!");
  };
}

const greeting = createGreeting();

greeting();
//Привіт!

Що тут відбувається?


  1. Створюється функція createGreeting().
  2. Усередині неї за допомогою return повертається інша функція.
  3. Виклик createGreeting() повертає функцію, яка записується в змінну greeting.
  4. За допомогою greeting() ми викликаємо отриману функцію.

Отже, createGreeting() — функція вищого порядку, оскільки вона повертає іншу функцію.
