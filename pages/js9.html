Recursion

a process in which a function calls itself to solve a problem.

1. Що таке рекурсія (Recursion)?

Рекурсія — це підхід у програмуванні, коли функція викликає саму себе для розв'язання меншої частини тієї самої задачі.


Простими словами: функція викликає себе знову і знову, поки не досягне умови зупинки. 


function countdown(n) {
    if (n === 0) {
        console.log("Стоп!");
        return;
    }

    console.log(n);
    countdown(n - 1);
}

countdown(5);
//5
  4
  3
  2
  1
  Стоп!

Як працює рекурсія всередині?


Коли функція викликає саму себе, попередній виклик не зникає. Він чекає, поки вкладений виклик завершиться.


Для цього використовується Call Stack (стек викликів). 


function test(n) {
    if (n === 0) return;

    console.log("Start:", n);
    test(n - 1);
    console.log("End:", n);
}

test(3);
//Start: 3
  Start: 2
  Start: 1
  End: 1
  End: 2
  End: 3

Це дуже важливий момент: спочатку рекурсія заглиблюється, а потім повертається назад.


2. Base Case та Recursive Case — як правильно будувати рекурсію

Щоб правильно створити рекурсивну функцію, потрібно розуміти дві її основні складові: Base Case (базовий випадок) та Recursive Case (рекурсивний випадок).



Base Case — це умова, за якої рекурсія припиняється і функція більше не викликає саму себе.


Простими словами: це точка зупинки рекурсії. 


function count(n) {
    if (n === 0) {
        return;
    }

    console.log(n);
    count(n - 1);
}

count(3);

У цьому прикладі:
if (n === 0) {
    return;
}
Це і є Base Case.

Коли значення n дорівнює 0, умова виконується, оператор return завершує поточний виклик функції.


Якщо не передбачити умову зупинки, функція продовжуватиме викликати саму себе без кінця, доки JavaScript не видасть помилку переповнення стека викликів (Maximum call stack size exceeded).



Recursive Case — це частина функції, у якій відбувається повторний виклик цієї самої функції з новими аргументами.


Простими словами: це те, що змушує функцію продовжувати виконання задачі, поступово наближаючись до умови зупинки. 


function count(n) {
    if (n === 0) {
        return;
    }

    console.log(n);
    count(n - 1);
}

Ось ця частина:
count(n - 1);
є Recursive Case.

Це дуже важливий момент: спочатку рекурсія заглиблюється, а потім повертається назад.


Приклад рекурсії: обчислення суми чисел


Створимо функцію sum(n), яка обчислює суму всіх натуральних чисел від 1 до переданого числа.

Наприклад, якщо передати число 5, результатом буде:

1 + 2 + 3 + 4 + 5 = 15


function sum(n) {
    if (n === 1) {
        return 1;
    }

    return n + sum(n - 1);
}

console.log(sum(5));
// 15

Як працює цей код?


1. Виклик функції: 


sum(5);

Ми передаємо у функцію число 5. Тому змінна n отримує значення 5.


2. Рекурсивні виклики:


Функція перевіряє умову n === 1. Оскільки 5 не дорівнює 1, вона переходить до рекурсивного виклику: 


return n + sum(n - 1);

JavaScript підставляє значення n = 5 та виконує віднімання 5 - 1. Тому наступний виклик буде sum(4). Кожного разу функція викликає себе з числом на одиницю менше.


Виклик Значення n Наступна дія
sum(5) 5 sum(4)
sum(4) 4 sum(3)
sum(3) 3 sum(2)
sum(2) 2 sum(1)
sum(1) 1 Зупинка

3. Умова зупинки (Base Case): 


if (n === 1) {
    return 1;
}

Коли n дорівнює 1, умова виконується. Функція повертає число 1 і більше не викликає себе.


4. Повернення результатів:


Після досягнення умови зупинки функція починає повертатися до попередніх викликів та виконувати відкладені обчислення. 


sum(1) = 1
sum(2) = 2 + 1  = 3
sum(3) = 3 + 3  = 6
sum(4) = 4 + 6  = 10
sum(5) = 5 + 10 = 15

Кожен попередній виклик додає своє значення n до результату наступного виклику.


Результат виконання: sum(5) = 15


Важливо запам'ятати:


  1. Спочатку функція викликає себе з меншими значеннями та доходить до Base Case.
  2. Base Case повертає початкове значення для обчислення — 1.
  3. Потім попередні виклики поступово виконують відкладені обчислення.
  4. Оператор return повертає результат наступного виклику, який використовується для подальшого обчислення.

3. Call Stack (Стек викликів)

Call Stack (стек викликів) — це механізм JavaScript, який відстежує виклики функцій та порядок їх виконання.


Простими словами: коли одна функція викликає іншу, JavaScript запам'ятовує, де потрібно продовжити виконання після завершення вкладеної функції.


Стек працює за принципом LIFO (Last In, First Out) — останнім прийшов, першим вийшов. Тобто, остання функція, яка потрапила у стек, виконається першою. Після її завершення JavaScript повернеться до попередньої функції. 


function first() {
    console.log("Перша функція");
}

function second() {
    first();
    console.log("Друга функція");
}

function third() {
    second();
    console.log("Третя функція");
}

third();
//Перша функція
  Друга функція
  Третя функція

Чому саме в такому порядку?


  1. Викликається third().
  2. Функція third() викликає second().
  3. Функція second() викликає first().
  4. first() завершується.
  5. JavaScript повертається до second()
  6. second() завершується.
  7. JavaScript повертається до third().

4. Factorial (Факторіал)

Факторіал (Factorial) — це добуток усіх натуральних чисел від 1 до заданого числа.


Факторіал позначається знаком !.


Наприклад:


3! = 1 × 2 × 3 = 6


4! = 1 × 2 × 3 × 4 = 24


5! = 1 × 2 × 3 × 4 × 5 = 120


0! = 1


function factorial(n) {

    if (n === 0 || n === 1) {
        return 1;
    }

    return n * factorial(n - 1);
}

console.log(factorial(5));
// 120

Як працює цей код?


1. Виклик функції: 


factorial(5);

Ми передаємо у функцію число 5. Тому змінна n отримує значення 5.


2. Рекурсивні виклики:


Функція перевіряє умову n === 0 || n === 1. Оскільки 5 не дорівнює 1/0, вона переходить до рекурсивного виклику: 


  return n * factorial(n - 1);

JavaScript підставляє значення n = 5 та виконує віднімання 5 - 1. Тому наступний виклик буде factorial(4). Кожного разу функція викликає себе з числом на одиницю менше.


Виклик Значення n Наступна дія
factorial(5) 5 factorial(4)
factorial(4) 4 factorial(3)
factorial(3) 3 factorial(2)
factorial(2) 2 factorial(1)
factorial(1) 1 Зупинка

3. Умова зупинки (Base Case): 


if (n === 0 || n === 1) {
    return 1;
}

Коли n дорівнює 1 або 0, умова виконується. Функція повертає число 1 і більше не викликає себе.


4. Повернення результатів:


Після досягнення умови зупинки функція починає повертатися до попередніх викликів та виконувати відкладені обчислення. 


factorial(1) = 1
factorial(2) = 2 * 1  = 2
factorial(3) = 3 * 2  = 6
factorial(4) = 4 * 6  = 24
factorial(5) = 5 * 24 = 120

Кожен попередній виклик множить своє значення n до результату наступного виклику.


Результат виконання: factorial(5) = 120
