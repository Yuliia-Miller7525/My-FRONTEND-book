JAVA SCRIPT

a high-level, interpreted programming language that adds interactivity, dynamic behavior, and logic to websites, working alongside HTML (structure) and CSS (styling).

JavaScript (JS) — це мова програмування, яка дозволяє створювати інтерактивні та динамічні вебсторінки.


Простими словами: JavaScript дозволяє вебсайту не просто відображати інформацію, а реагувати на дії користувача.

Наприклад:

  • Натискаєш на кнопку — відкривається меню.

  • Заповнюєш форму — сайт перевіряє введені дані.

  • Натискаєш на картку товару — відкривається його сторінка.

  • Вводиш текст у пошук — з'являються результати.

  • Натискаєш на кнопку «Темна тема» — змінюється оформлення сайту.

Для чого використовується JavaScript?

Інтерактивність - реагує на натискання кнопок.

Динамічний контент - додає, видаляє та змінює елементи сторінки.

Робота з формами - перевіряє дані користувача.

Анімації - створює рух та ефект.

Робота з сервером - отримує та відправляє дані.

Frontend - створює логіку інтерфейсу.

Backend - створює серверну частину за допомогає Node.js.

Де виконується JavaScript?

JavaScript може виконуватися в різних середовищах. Найчастіше ти зустрічатимеш два: JavaScript у браузері та JavaScript у Node.js


V8 — це JavaScript-двигун (JavaScript engine), розроблений Google. Він перетворює JavaScript-код на машинний код, який може виконуватися процесором. Він використовується, зокрема, у Google Chrome та Node.js.
