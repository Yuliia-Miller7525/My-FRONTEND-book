1. Що таке функції (Functions)?

Функція (functions) — це окремий блок коду, який виконує певну задачу та може використовуватися багато разів.


Простими словами, функція — це набір інструкцій, який ми створюємо для виконання певної дії.


Наприклад, функція може:


  • додавати числа;
  • обчислювати середнє значення;
  • перевіряти, чи число парне;
  • виводити повідомлення;
  • генерувати випадковий пароль.

Для чого потрібні функції?


Повторно використовувати код — не потрібно писати однаковий код декілька разів.

Організовувати код — розділяти велику програму на менші частини.

Спрощувати програму — кожна функція відповідає за конкретну задачу.

Полегшувати виправлення помилок — можна працювати з окремою функцією, не змінюючи всю програму.


Як працює функція?


Уявімо, що функція — це маленький помічник. Її роботу можна умовно поділити на три етапи:


  1. Вхідні дані (Input) — функція отримує інформацію.
  2. Обробка (Process) — виконує потрібні дії.
  3. Результат (Output) — повертає або виводить результат.

Важливо: не кожна функція обов'язково отримує дані або повертає результат. Це залежить від її призначення. 


functions addNumbers(a, b) {
  let result = a + b;

  return result;
}

console.log(addNumbers(5, 3));
// 8

2. Способи створення функцій (Function Creation)


functions Declaration (Оголошення функції) — це спосіб створення (оголошення) функції за допомогою ключового слова functions, назви функції та блоку коду.


Простими словами, це спосіб повідомити JavaScript, що ми хочемо створити функцію, яка виконуватиме певну задачу.


Синтаксис: 
functions functionsName() {
}

Елемент Що означає
functions Ключове слово, яке використовується для створення функції.
functionsName Назва функції.
() Круглі дужки, у яких записуються параметри функції.
{} Фігурні дужки, усередині яких записується тіло функції.
Тіло функції Частина функції, у якій записуються команди, які вона повинна виконати.

Правила іменування функцій


  • функції повинна описувати дію, яку виконує функція;
  • починатися з літери, _ або $;
  • не містити пробілів;
  • не бути зарезервованим словом JavaScript.

Важливо: коли ми оголошуємо функцію, JavaScript запам'ятовує її код, але не виконує його автоматично. Щоб функція виконалася, її потрібно викликати.


Функцію, створену через Function Declaration, можна викликати ще до її оголошення в коді. JavaScript заздалегідь обробляє оголошення таких функцій, тому виклик до місця оголошення працює. 


function showUserInfo(name, age, city) {
  console.log(`Ім'я: ${name}`);
  console.log(`Вік: ${age}`);
  console.log(`Місто: ${city}`);
}

showUserInfo("Олександр", 25, "Київ");
//Ім'я: Олександр
  Вік: 25
  Місто: Київ



Function Expression — це спосіб створення функції, коли функція записується у змінну як значення.


На відміну від Function Declaration, тут функція не оголошується окремою конструкцією з ім'ям, а присвоюється змінній.


Синтаксис: 
const functionName = function(parameters) {
  // Код, який виконує функція
};

Елемент Що означає
const Cтворює змінну, якій присвоюється функція.
functionName Ім'я змінної, через яку ми будемо викликати функцію.
function ключове слово для створення функції.
(parameters) Параметри функції.
{Тіло функції} Тіло функції. 

const sayHello = function() {
  console.log("Привіт!");
};

sayHello();
//Привіт!

Важливо: Function Expression можна викликати тільки після того, як функція була створена та присвоєна змінній. Якщо спробувати викликати sayHello() до створення функції, виникне помилка.


Function Expression може бути двох видів:


Анонімний (Anonymous Function) — функція без власного імені. 


const sayHello = function() {
  console.log("Привіт!");
}
//Тут функція не має власного імені.
Для її виклику використовуємо
ім'я змінної sayHello.

Іменований (Named Function Expression) — функція, яка має власне ім'я. 


const sayHello = function greeting() {
  console.log("Привіт!");
};

sayHello();
//sayHello — ім'я змінної,
greeting — власне ім'я функції.

3. Виклик функцій (Function Invocation)


Виклик функції (Function Invocation) — це виконання коду, який знаходиться всередині функції.


Коли ми створюємо функцію, JavaScript лише запам'ятовує її інструкції. Сам код функції не виконується автоматично. Щоб функція виконала свою роботу, її потрібно викликати.


Для виклику функції потрібно написати її назву та круглі дужки ().


Синтаксис: 
functionName();

function sayHello() {
  console.log("Привіт!");
}

// Викликаємо функцію
sayHello();
Результат у консолі: Привіт!

Як це працює?


  1. JavaScript зустрічає оголошення функції sayHello().
  2. Запам'ятовує код, який знаходиться всередині функції.
  3. До моменту виклику функція не виконує свої інструкції.
  4. Коли JavaScript зустрічає sayHello(), він переходить усередину функції.
  5. Виконує команду console.log("Привіт!").

Ми можемо викликати функцію та передавати їй дані, з якими вона повинна працювати. Для цього під час виклику функції в круглих дужках () вказуємо аргументи. 


function greetUser(name) {
  console.log(`Привіт, ${name}!`);
}

// Викликаємо функцію та передаємо аргумент
greetUser("Олена");
Результат у консолі: Привіт, Олена!

Можна викликати одну й ту саму функцію декілька разів, передаючи різні аргументи: 


function greetUser(name) {
  console.log(`Привіт, ${name}!`);
}

greetUser("Олена");
greetUser("Андрій");
greetUser("Марія");

Результат у консолі:
Привіт, Олена!
Привіт, Андрій!
Привіт, Марія!

Таким чином, нам не потрібно створювати окрему функцію для кожного імені. Ми використовуємо одну функцію, але передаємо їй різні дані.


Функція може приймати не один, а декілька аргументів. У такому випадку під час виклику ми передаємо їх через кому, дотримуючись порядку параметрів. 


function showMessage() {
  console.log("Вітаю на нашому сайті!");
}

showMessage();
Результат у консолі:
Вітаю на нашому сайті!

Не кожна функція потребує отримання даних під час виклику. Якщо функція не має параметрів, ми просто викликаємо її за допомогою назви та круглих дужок. 


function calculateSum(a, b) {
  console.log(a + b);
}

// Викликаємо функцію
calculateSum(5, 3);
Результат у консолі: 8

4. Параметри та аргументи функцій (Parameters & Arguments)


Під час створення функції ми можемо передбачити спеціальні змінні, у які будуть передаватися дані. Такі змінні називаються параметрами (Parameters).


Аргументи (Arguments) — це конкретні значення, які ми передаємо функції під час її виклику. 


function greetUser(name) {
  console.log(`Привіт, ${name}!`);
}

greetUser("Олена");

//тут: name — параметр функції.
"Олена" — аргумент.

Запам'ятай різницю:

Параметр — це змінна, яку ми вказуємо під час створення функції.

Аргумент — це значення, яке ми передаємо під час виклику функції.


Коли ми викликаємо функцію та передаємо їй аргументи, JavaScript присвоює ці значення відповідним параметрам. Тобто кожен параметр отримує значення аргументу, який стоїть на відповідній позиції.


Функція може мати декілька параметрів. Це дозволяє передавати їй одразу кілька значень. Параметри вказуються через кому під час створення функції, а аргументи — через кому під час її виклику.


Аргументи передаються параметрам послідовно, зліва направо. Якщо переплутати порядок аргументів, функція отримає інші значення, навіть якщо всі вони передані правильно.


Запам'ятай:

Перший аргумент передається першому параметру, другий — другому і так далі.


Якщо під час виклику функції ми не передали значення для певного параметра, JavaScript автоматично присвоює цьому параметру значення Undefined. undefined означає, що значення не було визначене.


Щоб замість undefined параметр отримував певне значення, ми можемо задати йому значення за замовчуванням (Default Parameter). Це значення буде використовуватися тоді, коли під час виклику функції аргумент не передали або передали undefined.


Синтаксис: 
function functionName(parameter = defaultValue) {
  // Код функції
}

function greetUser(name = "Гість") {
  console.log(`Привіт, ${name}!`);
}

greetUser();
//Привіт, Гість!

Значення за замовчуванням використовується лише тоді, коли аргумент відсутній або дорівнює undefined. Якщо передати null, JavaScript використає саме null. Тобто null не запускає використання значення за замовчуванням.

5. Повернення значення з функції (Return Statement)


return — це ключове слово JavaScript, яке використовується для повернення результату роботи функції.


Простіше кажучи, за допомогою return функція може не просто виконати певну дію, а й передати отриманий результат назад у те місце, звідки її викликали. 


function calculateSum(a, b) {
  return a + b;
}

calculateSum(5, 3);

У цьому прикладі:


  1. Створюємо функцію calculateSum() з параметрами a та b.
  2. Під час виклику передаємо аргументи 5 та 3.
  3. Функція додає ці значення.
  4. Return повертає результат обчислення — 8.

return дозволяє функції передати результат своєї роботи туди, де її викликали. Повернене значення можна записати у змінну, використати в іншому обчисленні або передати іншій функції.


Різниця між return та console.log()


Це один із найважливіших моментів, який потрібно зрозуміти. На перший погляд може здатися, що return та console.log() роблять одне й те саме, адже обидва можуть показувати результат роботи функції.


Але насправді вони виконують різні завдання:


  • console.log() — виводить інформацію в консоль.
  • return — повертає значення з функції, щоб його можна було використовувати далі в програмі.


Коли функція повертає результат через return, ми можемо використовувати його в інших частинах програми.


Є декілька поширених способів використання поверненого значення:


  1. Записати результат у змінну.

    2. ffunction calculateSum(a, b) {
  return a + b;
}

let result = calculateSum(10, 5);

console.log(result);
//15

  2. Використати результат у математичних операціях. 

    3. function multiply(a, b) {
  return a * b;
}

let result = multiply(5, 4) + 10;

console.log(result);
//30

  3. Використати результат у математичних операціях. 

    4. function calculateSum(a, b) {
  return a + b;
}

function showResult(result) {
  console.log(`Результат: ${result}`);
}

showResult(calculateSum(10, 5));
//Результат: 15



Ще одна дуже важлива особливість return — після його виконання функція одразу припиняє свою роботу. Це означає, що команди, які знаходяться після return, уже не виконуються. 


function showMessage() {
  console.log("Початок функції");

  return "Привіт!";

  console.log("Кінець функції");
}

let result = showMessage();

console.log(result);
//Початок функції
  Привіт!


У JavaScript кожна функція повертає якесь значення. Навіть якщо ми не прописали return самостійно. Якщо у функції немає оператора return, JavaScript автоматично повертає спеціальне значення undefined. 


function sayHello() {
  console.log("Привіт!");
}

let result = sayHello();

console.log(result);
//Привіт!
  undefined

function calculateSum(a, b) {
  let sum = a + b;
}

let result = calculateSum(5, 3);

console.log(result);
//undefined
