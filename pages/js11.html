This Keyword

refers to the object that a function is called on

this — це ключове слово JavaScript, яке посилається на об'єкт, що визначається способом виклику функції. Простіше кажучи, this допомагає функції звертатися до властивостей та методів певного об'єкта. 


const user = {
  name: "Alex",
  age: 25,

  showInfo: function () {
    console.log(this.name);
    console.log(this.age);
  },
};

user.showInfo();
//Alex
//25

Розберімо, що відбувається:


  1. Ми створили об'єкт user.
  2. Усередині об'єкта створили метод showInfo().
  3. Усередині методу використали this.
  4. Оскільки функцію викликаємо через user.showInfo(), значення this посилається на об'єкт user.
  5. this.name — це user.name.
  6. this.age — це user.age.

Важливо запам'ятати: this не визначається місцем, де функцію написали. Його значення залежить від того, як функцію викликали (для звичайних функцій).


Найчастіше на початку вивчення JavaScript ми зустрічаємо this саме всередині методів об'єктів. 


const car = {
  brand: "BMW",
  model: "X5",
  year: 2024,

  getInfo: function () {
    return `${this.brand} ${this.model}, ${this.year}`;
  },
};

console.log(car.getInfo());
//BMW X5, 2024

Завдяки this ми можемо використовувати один і той самий метод для різних об'єктів. 


const user1 = {
  name: "Anna",

  sayHello: function () {
    console.log(`Hello, ${this.name}!`);
  },
};

const user2 = {
  name: "John",

  sayHello: function () {
    console.log(`Hello, ${this.name}!`);
  },
};

user1.sayHello();
user2.sayHello();
//Hello, Anna!
//Hello, John!

1. this у методах об'єктів


Як ми вже з'ясували, якщо викликати метод через об'єкт, this посилатиметься на цей об'єкт. 


const user = {
  name: "Alex",

  sayHello: function () {
    console.log(`Hello, ${this.name}!`);
  },
};

user.sayHello();
//Hello, Alex!

Але що буде, якщо ми спробуємо викликати цю функцію окремо від об'єкта? 


const user = {
  name: "Alex",

  sayHello: function () {
    console.log(`Hello, ${this.name}!`);
  },
};

const greeting = user.sayHello;

greeting();

У цьому випадку результат буде іншим. Річ у тому, що ми не викликаємо метод через user.sayHello(). Ми присвоїли посилання на функцію іншій змінній greeting, а потім викликали її окремо. Ми не створюємо нову функцію і не копіюємо сам об'єкт. Ми лише зберігаємо посилання на функцію. Тому this більше не посилається на user.


Якщо вже викликаємо функцію окремо, без user:


  1. Якщо строгий режим ("use strict") - this буде дорівнювати undefined. Простіше кажучи, JavaScript не знає, до якого об'єкта потрібно звертатися.
  2. Якщо звичайний режим (без "use strict") - у браузері this буде посилатися на глобальний об'єкт window. window — це глобальний об'єкт браузера, який містить багато властивостей і методів, доступних на рівні браузерного середовища.

Головне, що потрібно запам'ятати: якщо звичайну функцію викликаємо через об'єкт, this посилається на цей об'єкт. Якщо викликаємо її окремо, без об'єкта, this вже не посилається на початковий об'єкт. Його значення залежить від режиму виконання. І ще один важливий момент: якщо this дорівнює undefined, спроба звернутися до this.name спричинить помилку. Це не означає, що this.name просто поверне undefined.

2. this у звичайних функціях (Global Context)


Global Context — це глобальний контекст виконання JavaScript, тобто середовище, у якому виконується код поза функціями та іншими окремими контекстами. Коли ми використовуємо this безпосередньо в глобальному коді, його значення залежить від середовища виконання.


У звичайному JavaScript-файлі, підключеному до HTML, без строгого режиму результатом буде глобальний об'єкт window. Тобто в глобальному контексті браузера this посилається на window. 


function showThis() {
  console.log(this);
}

showThis();

Тут функцію викликаємо самостійно, без об'єкта. Тому результат залежить від режиму виконання: звичайний режим у браузері - window, строгий режим ("use strict") - undefined. 


const user = {
  name: "Alex",

  showName: function () {
    console.log(this.name);
  },
};

function showInfo() {
  console.log(this);
}

user.showName();
showInfo();
//Alex
//Window {...}

3. this в Arrow Functions


На відміну від звичайних функцій, стрілкові функції не створюють власного значення this. Замість цього вони використовують this із зовнішнього контексту, тобто з того місця, де були створені. Це називається лексичним this (Lexical this). 


const user = {
  name: "Alex",

  sayHello: () => {
    console.log(`Hello, ${this.name}!`);
  },
};

user.sayHello();
//Hello, undefined!

Стрілкова функція не отримує this від об'єкта user. Вона бере this із зовнішнього контексту, у якому була створена. У цьому прикладі зовнішній контекст — глобальний контекст браузера, де this посилається на window. У window немає властивості name зі значенням "Alex", тому результатом буде undefined (за умови, що відповідну глобальну властивість не задано).


Висновок: якщо нам потрібно звертатися до властивостей самого об'єкта через this, зазвичай варто використовувати звичайну функцію для створення методу об'єкта.

Але це не означає, що ми взагалі не можемо використовувати стрілкові функції разом із this. Навпаки, вони дуже корисні, коли знаходяться всередині звичайного методу об'єкта. 


const user = {
  name: "Alex",

  sayHello: function () {
    const greeting = () => {
      console.log(`Hello, ${this.name}!`);
    };

    greeting();
  },
};

user.sayHello();
//Hello, Alex!

Розберімо по черзі:


  1. Ми створили об'єкт user.
  2. Усередині нього створили звичайний метод sayHello().
  3. Метод викликається через user.sayHello(), тому this у методі посилається на user.
  4. Усередині методу створили стрілкову функцію greeting().
  5. Стрілкова функція бере this із зовнішньої функції sayHello().

Ще одна ситуація, де стрілкові функції дуже корисні, — це callback-функції (функції зворотного виклику). Наприклад, використання setTimeout(): 


const user = {
  name: "Alex",

  sayHello: function () {
    setTimeout(() => {
      console.log(`Hello, ${this.name}!`);
    }, 1000);
  },
};

user.sayHello();
//Hello, Alex!

Чому це працює?


  1. Метод sayHello() викликається через user.
  2. Тому this у ньому посилається на user.
  3. Стрілкова функція всередині setTimeout() успадковує це значення this.
  4. Через одну секунду виводиться ім'я користувача.

4. this у різних типах функцій


Function Declaration — це оголошення функції за допомогою ключового слова function.


Синтаксис: 
function showName() {
  console.log(this.name);
}

Така функція має власне this. Його значення залежить від способу виклику. 


const user = {
  name: "Alex",
};

function showName() {
  console.log(this.name);
}

user.showName = showName;

user.showName();
//Alex


Function Expression — це створення функції та присвоєння її змінній.


Синтаксис: 
const showName = function () {
  console.log(this.name);
};

Щодо this, Function Expression працює так само, як Function Declaration. 


const user = {
  name: "Anna",
};

const showName = function () {
  console.log(this.name);
};

user.showName = showName;

user.showName();
//Anna


Arrow Function — це стрілкова функція, яка записується за допомогою стрілки =>.


Синтаксис: 
const showName = () => {
  console.log(this.name);
};

На відміну від двох попередніх варіантів, стрілкова функція не має власного this. Вона використовує this із зовнішнього контексту, у якому була створена. 


const user = {
  name: "Anna",

  showName: () => {
    console.log(this.name);
  },
};

user.showName();
//У звичайному браузерному скрипті
результат буде undefined
(якщо глобальне this.name не задано).

Порівняння трьох типів функцій


Особливість Function Declaration Function Expression Arrow Function
Має власний this Так Так Ні
this визначається під час виклику Так Так Ні
Успадковує this із зовнішнього контексту Ні Ні Так
Може використовуватися як метод об'єкта з власним this Так Так Ні

5. Методи call(), apply() та bind()


5.1 Метод call()


call() дозволяє викликати функцію та самостійно вказати, який об'єкт використовувати як this.


Синтаксис: 
function.call(thisArg, arg1, arg2, ...);
Де:
- thisArg — об'єкт,
на який має посилатися this.
- arg1, arg2 — аргументи,
які передаються у функцію.

const user = {
  name: "Alex",
  age: 25,
};

function showInfo(city, country) {
  console.log(`Мене звати ${this.name}.`);
  console.log(`Мені ${this.age} років.`);
  console.log(`Я живу в ${city}, ${country}.`);
}

showInfo.call(user, "Kyiv", "Ukraine");
//Мене звати Alex.
  Мені 25 років.
  Я живу в Kyiv, Ukraine.

Одна з переваг call() — ми можемо використовувати одну функцію для різних об'єктів, не створюючи її повторно. 


const user1 = {
  name: "Anna",
  age: 22,
};

const user2 = {
  name: "John",
  age: 30,
};

function showUser() {
  console.log(`Ім'я: ${this.name}, вік: ${this.age}`);
}

showUser.call(user1);
showUser.call(user2);
//Ім'я: Anna, вік: 22
//Ім'я: John, вік: 30

5.2 Метод apply()


apply() працює майже так само, як call(): він викликає функцію та дозволяє самостійно вказати, на який об'єкт має посилатися this. Але є одна важлива відмінність: аргументи функції передаються у вигляді масиву.


Синтаксис: 
function.apply(thisArg, [arg1, arg2, ...]);
Де:
- thisArg — об'єкт,
на який має посилатися this.
- [arg1, arg2, ...] — масив аргументів,
які передаються у функцію.

const user = {
  name: "Alex",
  age: 25,
};

function showInfo(city, country) {
  console.log(`Мене звати ${this.name}.`);
  console.log(`Мені ${this.age} років.`);
  console.log(`Я живу в ${city}, ${country}.`);
}

showInfo.apply(user, ["Kyiv", "Ukraine"]);
//Мене звати Alex.
  Мені 25 років.
  Я живу в Kyiv, Ukraine.

apply() зручно використовувати, коли аргументи функції вже зібрані в масив. 


const numbers = [10, 20, 30, 40, 50];

const result = Math.max.apply(null, numbers);

console.log(result);
//50

5.3 Метод bind()


bind() дозволяє створити нову функцію з прив'язаним значенням this. На відміну від call() та apply(), він не викликає функцію одразу. Він лише створює нову функцію, яку ми можемо викликати пізніше.


Синтаксис: 
const newFunction = functionName.bind(thisArg);

functionName — функція,
для якої ми хочемо закріпити this.
thisArg — об'єкт,
який буде значенням this.
newFunction — нова функція
з прив'язаним this.

const user = {
  name: "Олена",
};

function showName() {
  console.log(this.name);
}

const showUserName = showName.bind(user);

showUserName();
//Олена

Як і call() та apply(), метод bind() може приймати аргументи функції. 


const user = {
  name: "Олена",
};

function greet(message) {
  console.log(`${message}, ${this.name}!`);
}

const greetUser = greet.bind(user, "Привіт");

greetUser();
//Привіт, Олена!
