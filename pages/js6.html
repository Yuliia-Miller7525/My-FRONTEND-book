Nested Functions & Scope

1. Вкладені функції (Nested Functions)

Вкладена функція (Nested Function) — це функція, яка створюється всередині іншої функції. Тобто одна функція може містити в собі іншу функцію.


Вкладені функції використовують, коли потрібно:


  • розділити велику функцію на менші частини;
  • винести окремі дії в допоміжні функції;
  • обмежити доступ до певних функцій, щоб вони були доступні лише всередині зовнішньої функції. 

function outerFunction() {
  function innerFunction() {
    console.log("Це вкладена функція");
  }

  innerFunction();
}

outerFunction();
//Це вкладена функція

Розберімо код:


  • outerFunction() — зовнішня функція.
  • innerFunction() — вкладена функція, яка знаходиться всередині зовнішньої.
  • innerFunction() — виклик вкладеної функції.
  • outerFunction() — виклик зовнішньої функції, під час виконання якої викликається і вкладена функція.

Важливо запам'ятати!

Вкладена функція може бути викликана всередині зовнішньої функції. Але безпосередньо ззовні звернутися до неї не можна, якщо вона оголошена локально всередині зовнішньої функції.


Доступ вкладених функцій до зовнішніх змінних


Одна з важливих особливостей вкладених функцій полягає в тому, що вкладена функція має доступ до змінних, оголошених у зовнішній функції. 


function outerFunction() {
  let message = "Привіт, JavaScript!";

  function innerFunction() {
    console.log(message);
  }

  innerFunction();
}

outerFunction();
//Привіт, JavaScript!

Вкладена функція може не лише отримувати значення зовнішніх змінних, а й змінювати їх. 


function counter() {
  let count = 0;

  function increase() {
    count++;
    console.log(count);
  }

  increase();
  increase();
  increase();
}

counter();
//1
  2
  3

Важливо запам'ятати!

Вкладена функція має доступ до змінних зовнішньої функції, навіть якщо вони оголошені через let або const. Водночас зовнішня функція не має автоматичного доступу до локальних змінних вкладеної функції.


2. Область видимості (Scope)

Область видимості (Scope) — це частина програми, у якій змінна або функція доступна для використання. Простіше кажучи, область видимості визначає, звідки саме ми можемо звертатися до змінної або функції. Наприклад, одну змінну можна використовувати в усьому коді, а іншу — лише всередині певної функції.


Простіше кажучи, область видимості визначає, звідки саме ми можемо звертатися до змінної або функції. Наприклад, одну змінну можна використовувати в усьому коді, а іншу — лише всередині певної функції.


У JavaScript є три основні типи областей видимості:


  1. Глобальна область видимості (Global Scope).
  2. Функціональна область видимості (Function Scope).
  3. Блокова область видимості (Block Scope).

Глобальна область видимості (Global Scope)


Глобальна область видимості (Global Scope) — це область, у якій змінні та функції доступні практично з будь-якої частини програми.


Якщо змінну оголосити поза всіма функціями та блоками, вона буде доступна в різних частинах коду. 


let userName = "Олена";

function showUser() {
  console.log(userName);
}

showUser();

console.log(userName);
//Олена
  Олена

Важливо запам'ятати!

Глобальні змінні доступні з різних частин програми. Однак не варто створювати надто багато глобальних змінних, оскільки це може ускладнити роботу з кодом і призвести до конфліктів між змінними.

Функціональна область видимості (Function Scope)


Функціональна область видимості (Function Scope) — це область, у якій змінні, оголошені всередині функції через let, const або var, доступні лише в межах цієї функції.


Простіше кажучи, якщо ми створили змінну всередині функції, то за межами цієї функції звернутися до неї не зможемо. 


function showMessage() {
  let message = "Привіт!";

  console.log(message);
}

showMessage();

console.log(message);
//Під час виклику showMessage()
у консолі з'явиться:
Привіт!

//Але наступний console.log(message)
спричинить помилку:
ReferenceError: message is not defined

Блокова область видимості (Block Scope)


Блокова область видимості (Block Scope) — це область, обмежена фігурними дужками { }, усередині якої доступні змінні, оголошені через let або const.


Блоками можуть бути:


  • умовні конструкції if, else;
  • цикли for, while;
  • окремі блоки коду { }.

if (true) {
  let message = "Привіт!";
  const number = 10;

  console.log(message);
  console.log(number);
}

console.log(message);
console.log(number);
//Привіт!
  10

Після виходу за межі блоку виникнуть помилки ReferenceError, оскільки змінні message та number оголошені всередині блоку через let і const.


Важлива особливість:

let та const — мають блочну область видимості

var — має функціональну область видимості, а не блочну. 


if (true) {
  var first = 10;
  let second = 20;
  const third = 30;
}

console.log(first);
// 10
console.log(second);
// ReferenceError
console.log(third);
// ReferenceError

3. Лексична область видимості (Lexical Scope)

Лексична область видимості (Lexical Scope) — це правило JavaScript, за яким доступ до змінних визначається місцем, де функція була оголошена в коді, а не місцем, звідки її викликали.


Простіше кажучи, JavaScript визначає доступність змінних за структурою коду. 


let userName = "Олена";

function showUser() {
  console.log(userName);
}

showUser();
//Олена

Чому функція showUser() бачить змінну userName?


  • Змінна userName оголошена в глобальній області видимості.
  • Функція showUser() оголошена в цій самій області.
  • Усередині функції можна звертатися до змінних зовнішньої області видимості. 

let message = "Глобальне повідомлення";

function outerFunction() {
  let message = "Повідомлення зовнішньої функції";

  function innerFunction() {
    console.log(message);
  }

  innerFunction();
}

outerFunction();
//Повідомлення зовнішньої функції

Чому виводиться саме це повідомлення, а не глобальне?


Тому що вкладена функція спочатку шукає змінну у власній області видимості. Якщо не знаходить, переходить до зовнішньої. У нашому прикладі:


  • Усередині innerFunction() змінної message немає.
  • У outerFunction() така змінна є.
  • Тому JavaScript використовує її значення.

Важлива особливість:

Лексична область видимості означає, що вкладена функція має доступ до змінних тих областей, усередині яких вона була оголошена.
